nginx location

  • =: Exact match (must all be equal)
  • ~: case sensitive, regular matching
  • ~*: ignore case, regular matching
  • ^~: Only needs to match the uri part, exact match
  • @: internal service jump, exact match

Priority:

  1. Exact match =
  2. Forward match ^~ /
  3. Case sensitive regex ~ /
  4. Case insensitive regex ~*
  5. Path match /

rule

The exact match rule is "maximum prefix".
The regular matching rule is "sequential matching". As long as the first one is matched, subsequent matching will be stopped.
Universal match "/" last match

nginx rewrite

rewrite ^(.*)$ /other/path/or/server/$1 break;
