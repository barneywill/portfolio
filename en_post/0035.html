If you often encounter the following errors when git pull:

  • Encountered end of file
  • fatal: The remote end hung up unexpectedly

Due to poor network conditions, you can change the network, or you can try to increase the configuration.

git config --global http.lowSpeedLimit 0
git config --global http.lowSpeedTime 999999
