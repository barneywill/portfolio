Logstash 3 - http application (in and out)

📅 March 19, 2019
📖 1 min read
👁️ 2295 views

One Logstash can be easily broken into two Logstash through http to achieve cross-server or cross-platform data synchronization. For example, the original process is

logstash: nginx log - > kafka

Break it into two

logstash1: nginx log - > http out

logstash2: http in - >kafka

Details are as follows

http out



  filter {
    ruby {
      code => "event.cancel if not event.get('message').include?'something'"
    }
  }


output {
    http {
      url => "http://test.server:10000"
      codec => "plain"
      format => "json"
      content_type => "application/json"
      http_method => "post"
    }
}




Unnecessary records can be skipped through filter


http in




input {
    http {
        host => "0.0.0.0"
        port => 10000
        additional_codecs => {"application/json"=>"json"}
        codec => "plain"
        threads => 4
        ssl => false
    }
}
