Azkaban is a very lightweight open source scheduling framework, suitable for secondary development, but it cannot be used directly in production environments. It has fatal flaws (for example, AzkabanWebServer is a single point and has not been repaired for more than a year). In some scenarios, its behavior is simple and crude (such as restarting AzkabanExecutorSe rver will cause all processes running on the server to fail), and manual intervention is often required. To reach the reliability level of the production environment, at least a lot of secondary development, and the official code is updated very quickly. Merging the code has a great risk of conflict. It is suitable for some small companies that do not have high reliability requirements and can get started quickly. It is not recommended to use;

 

As a top-level Apache project, Oozie is widely used, has rich functions, high code quality, is mature and reliable, but the code and deployment are relatively complex, so it is recommended to use it;
