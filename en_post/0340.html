When Oozie submits a Spark task, it reports Java.lang.NoClassDefFoundError: org/apache/Kafka/clients/producer/KafkaProducer

📅 December 12, 2018
📖 1 min read
👁️ 3747 views

Oozie supports many action types, such as Spark and Hive, and the corresponding tags are:

<spark xmlns="uri:oozie:spark-action:0.1"> 

...

Sharelib in Oozie is used to store the dependencies required by each action type. You can view all current action types and the dependencies of each action type.

oozie admin - shareliblist
[Available ShareLib]
hive
sparkbak
distcp
mapreduce-streaming
spark
oozie
hcatalog
hive2
sqoop
pig

 

oozie admin - shareliblist spark

...

The above error is due to the lack of Kafka-clients-0.8.2.2.jar in the Kafka basic dependency in Spark dependency in Oozie. Upload the jar to the sharelib directory and then update it manually.

oozie admin - sharelibupdate

Visible after update:

 oozie admin -shareliblist spark|grep kafka
        hdfs://hdfs_name/oozie/share/lib_20180801121138/spark/kafka-clients-0.8.2.2.jar
        hdfs://hdfs_name/oozie/share/lib_20180801121138/spark/kafka_2.11-0.8.2.1.jar
        hdfs://hdfs_name/oozie/share/lib_20180801121138/spark/spark-streaming-kafka-0-8_2.11-2.1.0.jar 

Added successfully
