MySQL time zone

📅 June 20, 2019
📖 1 min read
👁️ 191 views

View current time zone

> show variables like '%time_zone%';
+------------------+--------+
| Variable_name    | Value  |
+------------------+--------+
| system_time_zone | UTC    |
| time_zone        | SYSTEM |
+------------------+--------+
2 rows in set (0.00 sec)

Temporarily modify time zone

> set time_zone = '+8:00';
Query OK, 0 rows affected (0.00 sec)

Completely change the time zone

# vi /etc/my.cnf

[mysqld]

default-time_zone = '+8:00'
