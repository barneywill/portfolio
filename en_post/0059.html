Large-Scale File Changes in Git

📅 July 20, 2020
📖 1 min read
👁️ 282 views

After recently moving the git project directory to another directory, I found that there were large-scale modifications in the git project.

View via git status

	modified:   .gitignore
	modified:   .README.md
...

View via git diff

diff --git a/.gitignore b/.gitignore
old mode 100644
new mode 100755
diff --git a/README.md b/README.md
old mode 100644
new mode 100755
...

It was found that there were no changes in the file content of these files, only changes in the file mode. The file mode was from 644 to 755.

There are two solutions at this time:

  • Modify file mode through chmod
  • git config --add core.filemode false
