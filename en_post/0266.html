At work, we often need to simulate http requests (such as modifying the header and body arbitrarily). curl is very easy to use. You can use

curl - h

Please refer to the detailed parameter list. Here are some commonly used parameters:

-v, --verbose Make the operation more talkative

Display detailed request and response information, mainly headers, status codes, etc.

-u, --user USER[:PASSWORD] Server user and password

Specify login account and password, -u user:password

-X, --request COMMAND Specify request command to use

Specify Method, such as Get, Post, Put, Delete, etc., -X GET

-x, --proxy [PROTOCOL://]HOST[:PORT] Use proxy on given port

Specify proxy server and port

-o, --output FILE Write output to <file> instead of stdout

Output the content to the specified file and use it when downloading

-H, --header LINE Custom header to pass to server (H)

Specify any header, -H 'Cookie: anything'

-d, --data DATA HTTP POST data (H)

Specify the body of the post, -d '{"name":"value"}'

You can also specify the contents of a file through -d, such as - d@/path/to/file

-F, --form <name=content> Specify multipart MIME data

 Support uploading files, such as - F "filename=@/test/test.tar.gz"
