redhat6 comes with glibc-2.12, the process of upgrading to glibc-2.14

# strings /lib64/libc.so.6 |grep GLIBC_
GLIBC_2.2.5
GLIBC_2.2.6
GLIBC_2.3
GLIBC_2.3.2
GLIBC_2.3.3
GLIBC_2.3.4

GLIBC_2.6
GLIBC_2.7
GLIBC_2.8
GLIBC_2.9
GLIBC_2.10
GLIBC_2.11
GLIBC_2.12
GLIBC_2.13
GLIBC_PRIVATE
# ls - l /lib64|grep libc.so
lrwxrwxrwx 1 root root 12 Jan 24 17:26 libc.so.6 - > libc-2.12.so

# wget http://ftp.gnu.org/gnu/glibc/glibc-2.14.tar.gz
# tar xvf glibc-2.14.tar.gz
# cd glibc-2.14
# mkdir build
# cd build
# /path/to/glibc-2.14/configure --prefix=/opt/glibc-2.14
# make
# make install

# export LD_LIBRARY_PATH=/opt/glibc-2.14/lib:$LD_LIBRARY_PATH

# cp /opt/glibc-2.14/libc-2.14.so /lib64/
# cd /lib64
# ln - snf libc-2.14.so libc.so.6

# strings /lib64/libc.so.6 |grep GLIBC_


Be sure not to use it when configuring

# /path/to/glibc-2.14/configure --prefix=/usr --disable-profile --enable-add-ons --with-headers=/usr/include --with-binutils=/usr/bin

Otherwise, once make install reports an error, the consequences may be serious. For details, see:https://www.cnblogs.com/barneywill/p/10315603.html
