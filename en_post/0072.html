lua cjson Converts Numbers to Scientific Notation

📅 January 15, 2020
📖 1 min read
👁️ 2045 views

When processing json, there is a field that is a number and the number of digits is very long, the result is processed as scientific notation

...,"tradeId":101200111072902276000243,...

The tradeId obtained after json.decode is 1.012001110729e+23

After trying various methods, it can only be solved through string replacement, using regular expressions

if not (string.find(str, '"tradeId"') == nil) then
  str=string.gsub(str, '("tradeId":)(%d+)', '%1"%2"')
end
