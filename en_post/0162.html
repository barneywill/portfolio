HDFS copy number

📅 March 25, 2019
📖 1 min read
👁️ 1131 views

When HDFS space is insufficient, in addition to deleting temporary data or junk data, you can also appropriately adjust the number of copies of some large directories in a multi-pronged approach;

1 View

$ hdfs dfs - ls /user/hive/warehouse/temp.db/test_ext_o
-rwxr-xr-x 3 hadoop supergroup 44324200 2019-02-28 16:36 /user/hive/warehouse/temp.db/test_ext_o/000000_0

The 3 after the permission is the number of copies

2 modifications

$ hadoop fs - setrep [-w] 2 /user/hive/warehouse/temp.db/test_ext_o/000000_0
or
$ hdfs dfs - setrep [-w] 2 /user/hive/warehouse/temp.db/test_ext_o/000000_0
WARNING: the waiting time may be long for DECREASING the number of replications.

Modify the number of copies to 2, and the startup path can specify a file or directory;
You can add the -w parameter and it will wait for the operation to complete;

The - w flag requests that the command wait for the replication to complete. This can potentially take a very long time.
