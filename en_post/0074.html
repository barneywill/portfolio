📅 January 11, 2020
📖 2 min read

First, you must have the HIVE_HOME environment variable.

If it is apache, configure it directly as the decompression directory; if it is CDH, set it as follows:

# export HIVE_HOME=/opt/cloudera/parcels/CDH-5.16.1-1.cdh5.16.1.p0.3/lib/hive

It still reports an error, saying that the class cannot be found. Copy it from the server directory to the hook/Hive directory.

# cp server/webapp/atlas/WEB-INF/lib/jackson-jaxrs-1.8.3.jar hook/hive/atlas-hive-plugin-impl/
# cp server/webapp/atlas/WEB-INF/lib/jackson-jaxrs-json-provider-2.9.2.jar hook/hive/atlas-hive-plugin-impl/
# cp server/webapp/atlas/WEB-INF/lib/jackson-module-jaxb-annotations-2.9.8.jar hook/hive/atlas-hive-plugin-impl/

The execution is successful again, and you can see Hive related data in atlas.
