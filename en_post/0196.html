Kerberos 2 - Hive Impala HDFS access

📅 March 02, 2019
📖 1 min read
👁️ 660 views

1 hive

# kadmin.local - q 'ktadd - k /tmp/hive3.keytab - norandkey hive/server03@TEST.COM'
# kinit - kt /tmp/hive3.keytab hive/server03@TEST.COM
# klist

# beeline - u 'jdbc:hive2://192.168.0.3:10000/;principal=hive/server03@TEST.COM'
# hive

Note that server03 here refers to the host of the Hive server, not the host of the client server;

2 impala

# kadmin.local - q 'ktadd - k /tmp/impala3.keytab - norandkey impala/server03@TEST.COM'
# kinit - kt /tmp/impala3.keytab impala/server03@TEST.COM
# klist

# impala-shell - i 192.168.0.3:21000 - k
# beeline - u 'jdbc:hive2://192.168.0.3:21050/;principal=impala/server03@TEST.COM'

 

3 hdfs

# kadmin.local - q 'ktadd - k /tmp/hdfs.keytab - norandkey hdfs/server01@TEST.COM'
# kinit - kt /tmp/hdfs.keytab hdfs/server01@TEST.COM
# klist
