Running Multiple Configuration Files in One Logstash Instance

📅 September 22, 2019
📖 1 min read
👁️ 2414 views

One instance of logstash runs multiple configuration files. Just put all configuration files in the following directory.

/usr/share/logstash/pipeline

However, the default behavior is not that each configuration file runs independently, but as a whole, each input will match all filters, and then match all outputs, which may cause data to be processed incorrectly and sent to the wrong place;

 

Solution one:

Set a variable in input and judge the variable in filter and output so that each configuration file can run independently without affecting each other. Which variable should be used?

Input has many common parameters by default, but only type is available. The official description is as follows:

Add a type field to all events handled by this input.

Types are used mainly for filter activation.

The type is stored as part of the event itself, so you can also use the type to search for it in Kibana.

The type parameter in the input will be added to the event, so it can be used in both filter and output later, but other parameters will not work. The configuration is as follows:

input {
  jdbc {
    ...
    type => "some_type"
  }
}
filter {
  if [type] == "some_type" {
    ...
  }
}
output {
  if [type] == "some_type" {
    ...
  }
}

If everything is normal, congratulations. If there are still problems, it is possible that there is a type field in your event, and then you assign a value, and a type array will appear (append rather than overwrite). At this time, there are two problems:

1) If the if judgment in filter and output is invalid, your data will not be processed or sent out at all;

2) The type field in your data has been changed;

 

Solution two:

Manually add a variable in the event, such as my_type, and configure it as follows:

input {
  jdbc {
    ...
    statement => "select *, 'some_type' my_type from my_table where update_time > :sql_last_value"
    ...
  }
}
filter {
  if [my_type] == "some_type" {
    ...
  }
}
output {
  if [my_type] == "some_type" {
    ...
  }
}
