View Hive complete execution of SQL on YARN

📅 December 07, 2018
📖 1 min read
👁️ 6271 views

The task name submitted to YARN when Hive executes SQL has been processed. Usually only the first paragraph and the last few characters of SQL can be displayed, which will cause some problems:

1) Several similar SQLs were submitted at similar times, and they are indistinguishable from each other;

2) There is a problem with a task. I want to see what the specific execution of this task is? Whose task is it?

You can view it through the following methods:

1) If the task is running, enter YARN's ApplicationMaster page, enter job, click configuration, and enter "Hive.query.string" in the filter box in the upper right corner, as shown in the figure:

2) If the task has ended, enter the history server, and the page will be similar to the above;
