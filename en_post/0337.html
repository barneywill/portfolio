How to choose HBase client

📅 December 12, 2018
📖 1 min read
👁️ 801 views

There are two ways to access HBase in Java, one is the client that comes with HBase, and the other is through HBase thrift

1 HBase client example

        Configuration conf = HBaseConfiguration.create();

        conf.set(HConstants.ZOOKEEPER_CLIENT_PORT, "2181");

        conf.set(HConstants.ZOOKEEPER_QUORUM, "zk_host");

        Connection connection = ConnectionFactory.createConnection(conf);

        Table profileTable = connection.getTable(TableName.valueOf("test_table"));

 

        Result result = profileTable.get(new Get(Bytes.toBytes("test_rowkey")));

        System.out.println(new String(result.getValue(Bytes.toBytes("test_cf"), Bytes.toBytes("test_column"))));

Here you only need to configure ZooKeeper. The access process is to first find hmaster through ZooKeeper, then locate a RegionServer through hmaster, and then access the RegionServer. Therefore, the client needs to be reachable to all HBase nodes (including ZooKeeper, hmaster, and RegionServer), that is, the host can ping successfully;

 

2 HBase thrift example

        TTransport transport = null;

        try {

            transport = new TSocket(host, port, timeout);

            transport.open();

            TProtocol protocol = new TBinaryProtocol(transport);

            THBaseService.Iface client = new THBaseService.Client(protocol);

            ByteBuffer table = ByteBuffer.wrap(tableName.getBytes());

            TGet get = new TGet(ByteBuffer.wrap(rowKey.getBytes()));

            try {

                TResult result = client.get(table, get);

                return result;

            } catch (Exception e) {

                throw new RuntimeException(e);

            }

        } catch (Exception e) {

            throw new RuntimeException(e);

        } finally {

            transport.close();

        }

Here you only need to configure the IP and port of the HBase thrift server, without any other dependencies; the single point problem can be solved by adding a load balancer;

 

In summary, if you do not need to configure a host, either method is fine. If you do need to configure a host, it is easier to use thrift;
