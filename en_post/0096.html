Hive Query Error: NoViableAltException

📅 July 30, 2019
📖 1 min read
👁️ 6387 views

When executing SQL character constants in Hive or spark containing;, an error will be reported, for example

select instr('abc;abc', ';');

Report an error

NoViableAltException(-1@[147:1: selectExpression : ( expression | tableAllColumns );])

Need to change; to ascii

select instr('abc\073abc', '\073');
