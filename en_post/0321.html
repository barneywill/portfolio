Oozie 3 - Oozie upgraded from 4.3 to 5.0

📅 December 13, 2018
📖 1 min read
👁️ 596 views

The official documentation is as follows:

http://oozie.apache.org/docs/5.0.0/AG_OozieUpgrade.html

What is written here is relatively simple, and the approximate process is as follows:
1 Download the 5.0 code and compile it;
2 Unzip the 5.0 package and replace Oozie-site.XML;
3 Stop all processes;
4. Upgrade DB according to the official documentation;
5 Restart Oozie;
6 Restore all processes;


At this time, the upgrade is completed. If you are careful enough, you will find that there is still a small problem. The Job DAG cannot be displayed. In Oozie's Job DAG image implementation in 5.0, graphviz is used instead, which needs to be installed.

yum install graphviz
