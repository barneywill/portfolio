ngx.req.get_body_data Returns nil in OpenResty (Nginx + Lua)

📅 July 27, 2019
📖 1 min read
👁️ 3456 views

Post data cannot be obtained in openresty (nginx+lua), ngx.req.get_body_data returns nil

This function returns nil if

  • the request body has not been read,
  • the request body has been read into disk temporary files,
  • or the request body has zero size.

Turn on nginx debug log

error_log /var/log/nginx/error.log debug;

Found the following log:

2019/07/26 10:41:43 [warn] 319#319: *3041588 a client request body is buffered to a temporary file /usr/local/openresty/nginx/client_body_temp/0000001574, client: 192.168.0.2, server: localhost, request: "POST /test HTTP/1.1", host: "192.168.0.1"

It can be seen that the body is too large and is buffered into a temporary file. In this case, ngx.req.get_body_file should be used.

fix code

function read_from_file(file_name)
  local f = assert(io.open(file_name, "r"))
  local string = f:read("*all")
  f:close()
  return string
end

ngx.req.read_body()
local body = ngx.req.get_body_data()
if (body == nil) then
  local body_file = ngx.req.get_body_file()
  if body_file then
    body = read_from_file(body_file)
  else
    ngx.status = 500
    ngx.say("error")
    return
  end
end
