CM Canary error report

1 HDFS Canary
Canary tests cannot create a parent directory for /tmp/.cloudera_health_monitoring_canary_files.

2 Hive Metastore Canary
Hive Metastore canary failed to create hue HDFS home directory.

examine:

1) Whether HDFS is in safemode, normal is off

# hdfs dfsadmin -safemode get
Safe mode is OFF

2) Check whether the HDFS DataNode is healthy and whether the disk space is free. You can upload files to test by yourself.

# hdfs dfsadmin -report

3) Check the directory permissions according to the error prompt. If there is any problem, change it to 777

# hdfs dfs -ls /tmp
Found 3 items
d--------- - hdfs supergroup 0 2019-02-18 23:57 /tmp/.cloudera_health_monitoring_canary_files
# hdfs dfs -chmod 777 /tmp/.cloudera_health_monitoring_canary_files

If you have confirmed everything and still get an error, please restart cloudera-scm-server.
