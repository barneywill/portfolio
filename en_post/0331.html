When creating a Hive table, should I use an internal table or an external table?

📅 December 12, 2018
📖 1 min read
👁️ 907 views

One of the main differences between internal tables and external tables is whether the underlying files will be automatically deleted when deleting a table or partition. Internal tables will be automatically deleted, but external tables will not be automatically deleted. Therefore, the basic data table must use an external table. Even if the table or partition is accidentally deleted, it can be easily restored.

Although external tables can be restored, it is tiring to restore partitions one by one. If you have many partitions or multiple levels of partitions,

alter table test_table add partition (partition_key='partition_value')

An easier way is to execute

msck repair table test_table

Restore all partitions with one click
