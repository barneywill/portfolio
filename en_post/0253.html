Users and groups

📅 January 22, 2019
📖 1 min read
👁️ 481 views

1 Add and delete users

# useradd $user
# userdel $user

2 Set user password

# passwd $user

/etc/passwd

3 View the user and group information of $user

# id $user

4 Add user $user to group $group

# usermod -G $group $user

or

# groupmems -g $group -a $user

5 Add and delete groups

# groupadd $group
# groupdel $group

6 View group members

# groupmems -g $group -l

or

# grep hadoop /etc/group

7 Remove user $user from group $group

# groupmems -g $group -d $user

8 User home directory related

The Linux user home directory is usually under /home/$user. There are two ways:

1) When creating a user

# useradd -m $user

2) Modify the user’s home directory

# usermod -d /path/to/home $user

9 Switch users

# su - $user

If an error is reported when switching users

This account is currently not available.

You need to modify /etc/passwd and change the last /sbin/nologin to /bin/bash; 

10 Specify or modify uid and gid

Add user test and group test, specify uid and gid are both 1001

# groupadd -g 1001 test
# useradd -u 1001 -g test test

Modify the uid of user test to 1001 and modify the gid of group test to 1001

# usermod -u 1001 test
# groupmod -g 1001 test
