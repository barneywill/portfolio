The AppMaster is the first container started by the ResourceManager when a YARN job runs. It then manages the entire job lifecycle, including requesting containers, launching them, killing them, and checking their status.
Each job type needs to provide its own AppMaster.
YARN only provides an AppMaster for MapReduce jobs.

5. Data Locality

Moving Computation is Cheaper than Moving Data

Spark Task Assignment Flow

job->stage-task
resourceOffer calls getAllowedLocalityLevel to determine which locality level is currently allowed for launching tasks. Internally, getAllowedLocalityLevel uses delay time and whether more tasks remain to control the allowed levels. For example, it may initially allow only PROCESS_LOCAL; after a delay, it may allow both PROCESS_LOCAL and NODE_LOCAL tasks.

Data locality levels: PROCESS_LOCAL, NODE_LOCAL, NO_PREF, RACK_LOCAL, ANY
Configuration: spark.locality.wait

Impala

Efficiently retrieving data from HDFS is a challenge for all SQL-on-Hadoop systems. In order to perform data scans from both disk and memory at or near hardware speed, Impala uses an HDFS feature called short-circuit local reads to bypass the DataNode protocol when reading from local disk. Impala can read at almost disk bandwidth (approx.100MB/s per disk) and is typically able to saturate all available disks. We have measured that with 12 disks, Impala is capable of sustaining I/O at 1.2GB/sec.
