Repairing location in Hive Metadata

📅 May 19, 2022
📖 1 min read
👁️ 400 views

If the location of the table or partition in Hive is wrong or missing and needs to be repaired in batches, you can refer to the following steps:

Repair table location

hdfs dfs - ls /data/hive/warehouse/$db | awk '{print $8}' |sed '1d' | awk - F '/' '{print "alter table "$5"."$7" set location ""$0"";"}'

The output SQL is executed in Hive

Repair the location of the partition

update DBS d, TBLS t, SDS ts, PARTITIONS p, SDS ps set ps.location = concat(ts.location, '/', p.part_name)
-> where d.db_id = t.db_id and t.sd_id = ts.sd_id and p.tbl_id = t.tbl_id and p.sd_id = ps.sd_id
-> and d.name = '$db';>

Execute the above command in the Hive metadata database

Confirm fix

select * from $db.$table limit 10
