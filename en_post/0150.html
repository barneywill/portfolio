1 vi configuration file

~/.vimrc
or
/etc/vimrc

ps: If you are using the vim plug-in in idea, the configuration file used is ~/.ideavimrc~~~`s

 

The color matching can be modified in the configuration file, the key bindings can be modified, and the configuration can be modified, such as

inoremap <C-a> <Home>

inoremap <C-e> <End>

inoremap <C-p> <Up>

inoremap <C-n> <Down>

inoremap <C-b> <Left>

inoremap <C-f> <Right>

 

colorscheme darkblue

Default color folder: /usr/share/vim/vim74/colors

Note that 74 is the version number

 

Two modes

Three modes: command mode, bottom line command mode, input mode

Command Mode

1 Move the cursor up/down/left/right

h Left

k Up

j Down

l RIght

Number+j|k|h|l can quickly move number characters

2 Cursor moves quickly

G (end of file)

1G (beginning of file)

gg 

10G (jump to the beginning of line 10)

10gg 

:10Enter 

10 Enter (cursor moves down 10 lines)

10j 

 

H (top row of current screen)

L (bottom row of current screen)

M (move the cursor to the middle line of the screen)

^ (start of line, no spaces, first non-whitespace character, soft start of line)

0 (Number 0, start of line, including spaces, first character, hard start of line)

$ (end of line)

- (previous line beginning, soft line beginning)

+ (beginning of next line, soft line beginning)

 

Space (move backward 1 character)

10 spaces (move backward 10 characters)

10l (lowercase L)

w (move to the beginning of the next word, where words are separated by non-letters)

W (move to the beginning of the next word, words here are separated by spaces)

e (move to the end of the next word, same as above)

E (words here are separated by spaces, same as above)

ge (reverse e)

b (move to the beginning of the previous word, same as above)

B (words here are separated by spaces, same as above)

 

( (move to the beginning of the previous sentence)

) (move to the beginning of the next sentence)

{ (move to the previous paragraph, separated by blank lines)

} (move to next paragraph, separated by blank line)

 

Ctrl+g (list editing information, including file name, line number, column number, etc.)

>> (indent, one tab)

<< (anti-indent, one tab)

 

f any character (move the cursor backward to the specified character)

F any character (move the cursor forward to the specified character)

tAny character (move the cursor to before the specified character)

T any character (move the cursor in the reverse direction to before the specified character)

10f any character (move the cursor backward to the 10th occurrence of the specified character)

; (repeat, repeat the above operation and continue to move the cursor to the next position)

, (reverse, return the cursor to the previous position)

3 turn pages

Ctrl+b (turn up one page)

Ctrl+u (turn up half a page)

Ctrl+f (turn down one page)

Ctrl+d (turn half page down)

Ctrl+e (the screen scrolls down, the cursor position remains unchanged, different from j)

Ctrl+y (Scroll up the screen, the cursor position remains unchanged, the difference is k)

4 search

/something (search down)

?something (search up)

n next N previous

 

# (Select the word currently under the cursor upwards)

* (Down to select the word currently under the cursor)

5 Delete characters

x (delete backward, Delete)

X (delete forward, Backspace)

10x (delete 10 characters backward)

10X (delete 10 characters forward)

dw (delete 1 word backward)

10dw (delete 10 words backward)

d^ (delete the cursor to the beginning of the line)

d0 

d$ (delete cursor to end of line)

D 

 

di' (remove characters between '')

da' (delete characters between '', including ')

di" (delete the characters between "")

da" (delete the characters between "", including ")

ci ca (modify)

yi ya (copy)

 

dd (delete current line)

dj (delete next line)

dk (delete previous line)

d10d (delete 10 lines)

10dd (delete 10 rows)

dG (Delete the line where the cursor is located to the end)

d1G (Delete the line where the cursor is to the first line)

6 Visual copy and paste

V (visual row mode, block selection mode, then move the cursor up and down until the desired row is selected)

v (Visual mode, then move the cursor left or right until the desired character is selected)

y (copy all selected characters)

d (cut selected characters)

p (paste the selected text to the line below the cursor)

P (paste the selected text to the line above the cursor)

 

7 copy

yy (copy entire line)

Y

10yy (copy 10 lines)

yw (copy next word)

10yw (copy the next 10 words)

yG (copy current line to last line)

y1G (copy the current line to the first line)

y0 (copy the current cursor to the beginning of the line)

y^

y$ (copy the current cursor to the end of the line)

 

The above cut and copy can only be used in vi with p. If you want to paste in other applications, you need to copy to the clipboard. The command is as follows:

"*yG (select all and copy)

8 undo&redo operations

u (undo restores to the state before editing)

U (undo restores the previous operation, press it again to repeat the last operation)

. (redo repeats the previous command, such as dw)

9 Temporary suspend and return

Ctrl+z (suspend)

fg (return)

10 marks

m any character (mark the current position of the cursor as any character)

`Any character (quick return mark)

'Any character (quickly returns to the beginning of the marked line)

:delmarks any character (unmark)

Last Line Mode

Command mode input: enter bottom line command mode, delete: or return to command mode after command execution

1 Show line number or cancel

:set number

:set nonumber

or

:set nu

:set nonu

2 automatic indentation

:set ai
or
:set autoindent

3 Smart indentation

:set si
or
:set smartindent

4 Cancel automatic indentation when pasting

:set noai nosi
or
:set paste

5 Text replacement a->b

:%s/a/b/g (all lines)

:s/a/b/g (current line)

:1,5s/a/b/g (lines 1-5)

 

:1,5s/^/#/b (Add comments on lines 1-5)

Another way, under vim

1) Ctrl+v (enter block selection mode)

2) j (move the cursor to select lines 1-5)

3) I (capital i, enter at the beginning of the line)

4) # (enter comment characters)

5) Esc (twice, exit block selection mode, and add comment characters at the beginning of lines 1-5)

 

6 Change the file format to unix

:set fileformat unix

7 Save & Exit

:w (save)

:q (quit)

:q! (discard modifications and exit, equal to ZQ)

:wq (save and exit, equal to ZZ)

 

8 Temporary execution of orders

:! some command (temporarily execute some command)

9 cut

:x,yd (cut lines x to y)

:x,y m z (move lines x to y after line z)

10 vim color matching

:colorscheme (View current color scheme)

:colorscheme darkblue (modify color scheme, permanent modification requires modification of .vimrc)

11 others

:h (help)

:e filename (open another file)

:new (open new file)

:sav filename (save as)

 

:sp [filename] (open another file and split the screen up and down at the same time)

:vsp [filename] (open another file and split the screen left and right)

:q (exit split screen)

Ctrl+w h|j|k|l (cursor moves between split screens)

 

Insert Mode

Start in command mode

1 Insert characters

i (insert after cursor)

I (insert at beginning of line)

a (append after cursor)

A (append at end of line)

o (Insert a newline from the current position and insert characters starting after the newline)

O (Insert a newline from the current position and insert characters starting before the newline)

r (replace the current character and return to command mode after replacement)

R (enter replacement mode)

c0 (Delete all characters from the cursor to the beginning of the line and enter insert mode)

c$ (Delete all characters from the cursor to the end of the line and enter insert mode)

C 

cc (delete the current line and enter insert mode)

cw (delete the word after the cursor and enter insert mode)

2 After entering input mode

Ctrl+w (delete 1 word to the left)

Ctrl+u (delete to the left to the beginning of the line)

Ctrl+h (delete 1 character to the left)

 

Ctrl+t (increase indent at beginning of line)

Ctrl+d (remove indent at beginning of line)

 

Ctrl+a (insert last inserted content)

Ctrl+@ (Insert the last inserted content and end insert mode)

 

Ctrl+o (Temporarily return to command mode, return to input mode after executing a command, to avoid switching modes back and forth)

 

Ctrl+u (restore last modification)

After vi enters the input mode, there are very few shortcut keys, such as moving the cursor. Although you can use Ctrl+o, it is still not as convenient as emacs. But the good news is that you can bind emacs shortcut keys in vi.

# vi .vimrc

inoremap <C-a> <Home>

inoremap <C-e> <End>

inoremap <C-p> <Up>

inoremap <C-n> <Down>

inoremap <C-b> <Left>

inoremap <C-f> <Right>

The above will be bound to shortcut keys such as Ctrl+aepnbf, which can be said to be a perfect combination of two swords.
