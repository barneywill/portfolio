Managing USB Drives and Portable Disks from the CentOS Command Line

📅 December 05, 2020
📖 1 min read
👁️ 765 views

After inserting the USB flash disk or mobile hard disk into the USB, use

fdisk - l

You can find the partition, such as /dev/sdc1, and then mount it

mount /dev/sdc1 /usb

If an error is reported, it may be a different file system problem, as follows:

1 ntfs file system

yum install ntfs-3g

mount - t ntfs-3g /dev/sdc1 /usb

2 exfat file system

yum install - y http://li.nux.ro/download/nux/dextop/el7/x86_64/nux-dextop-release-0-5.el7.nux.noarch.rpm

yum install exfat-utils fuse-exfat

mount - t exfat /dev/sdc1 /usb

If you find that the Chinese file name is garbled after opening the USB flash drive or mobile hard disk, you need to set the character set, such as

mount - o iocharset=utf8 /dev/sdc1 /usb

After using the USB flash drive or mobile hard disk, you need to eject it first and then remove it. The ejection operation is as follows:

yum install udisks2

udisksctl unmount - b /dev/sdc1

udisksctl power-off - b /dev/sdc1

If the write operation prompts readonly file system, you need to mount it again.

mount - o remount rw /path
