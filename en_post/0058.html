Sometimes there will be an abnormal initialization of the Java plug-in. The phenomenon is that the thumb position keeps spinning in circles without any error.

At this time, you can perform the following operations:

  • Set java.trace.server=verbose

    set up
  • Open developer tools (open the command panel and enter developer tools)
    Plug-in org.eclipse.jdt.ls.core was unable to load class org.eclipse.jdt.ls.core.internal.LanguageServero

Then you see the following error:

Plug-in org.eclipse.jdt.ls.core was unable to load class org.eclipse.jdt.ls.core.internal.LanguageServero

There is a way to solve it. Copy the code project to another directory and then open it. The reason is unknown.
