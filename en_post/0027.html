Logstash Kafka Consumption Lag

📅 May 18, 2022
📖 1 min read
👁️ 512 views

background

In the logstash cluster, the server configuration and task configuration of each node are the same, but one of the nodes has a relatively large consumption delay.

position

It was observed that the load of the node with the problem was much lower than that of other nodes. Further comparison of the threads in the logstash process revealed that the node with the problem had only 4 worker processes, while the normal node had 16 worker processes.

Further investigation revealed that the logstash configuration of the problematic node was different from that of other nodes.

/etc/logstash/logstash.yml
pipeline.workers: 4

This configuration is used to set the number of workers. The number of CPU cores is used by default. The server configuration is 16 cores. In fact, only 4 cores are used, and only 25% of the CPU is used, so there is a consumption delay.

Summarize

The Logstash cluster does not have unified cluster configuration management, which leads to this problem. In addition to this parameter, there are other parameters that may also affect consumption performance, such as pipeline.batch.size
