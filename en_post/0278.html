Check the Linux distribution and kernel version

📅 January 10, 2019
📖 1 min read
👁️ 535 views

Red Hat view distribution version

# cat /etc/redhat-release
CentOS Linux release 7.2.1511 (Core)

View kernel version

# uname - a
Linux $host 3.10.0-327.28.3.el7.x86_64 #1 SMP Thu Aug 18 19:05:49 UTC 2016 x86_64 x86_64 x86_64 GNU/Linux

or

# cat /proc/version
Linux version 3.10.0-327.28.3.el7.x86_64 (builder@kbuilder.dev.centos.org) (gcc version 4.8.3 20140911 (Red Hat 4.8.3-9) (GCC) ) #1 SMP Thu Aug 18 19:05:49 UTC 2016
