Let’s go back to the beginning. Google started out as a search engine. To put it simply, a search engine requires a bunch of crawlers to crawl all the web pages on the entire network according to certain rules. Then it needs to extract the content of these web pages, and then segment the content and build an inverted index. When the user searches, the user’s search keywords are segmented into words and then checked in the inverted index and combined with some weights to sort the results and return them to the user in pages.

In fact, many details are ignored here. For example, to store all original web page data after crawling, distributed file storage is required, so GFS appears; in GFS, distributed consistency issues need to be solved, so Chubby appears; when results are sorted, page weights need to be referenced, that is, to calculate PageRank, so the computing model MapReduce appears; web page data needs to retain historical versions, support massive real-time writing, and support real-time random access, such as the web page snapshot function, so BigTable appears. . .

3 HDP（Hortonworks Data Platform）

HDP is the industry's only true secure, enterprise-ready open source Apache™ Hadoop® distribution based on a centralized architecture (YARN). HDP addresses the complete needs of data-at-rest, powers real-time customer applications and delivers robust big data analytics that accelerate decision making and innovation. 

 

 Why are there so many distributions? To put it simply, CDH and HDP are both based on Apache. If you use Apache directly, the version of each component is chosen arbitrarily, and version compatibility issues are easy to occur. CDH and HDP are equivalent to packaging a series of version-compatible components and naming a new version, and the updates are relatively lagging; in addition, there will be some unique components, such as CDH's Cloudera Manager, Hue, Impala, etc., HDP's Ambari, etc., which facilitate cluster construction, management, monitoring, etc.;

Ambari is more open and supports the installation of third-party components, such as Elasticsearch, Airflow, Impala, Hue, etc. For details, see:https://www.cnblogs.com/barneywill/p/10268501.html

ps: Cloudera and Hortonworks have recently merged, and CDH and HDP may be further integrated in the future.
