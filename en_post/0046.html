Bluetooth Devices Frequently Disconnect on Linux

📅 December 13, 2020
📖 1 min read
👁️ 2408 views

After the Linux system has been running for a period of time, the Bluetooth device fails, but the connection status is still displayed in the system. At this time, you need to turn off and on Bluetooth and then reconnect the device to restore it.

To completely solve the problem, you need to modify grub

# vim /etc/default/grub
GRUB_CMDLINE_LINUX="usbcore.autosuspend=-1 "

Update after modification

# grub-update

If there is no grub-update command, such as opensuse, use the following command

# grub2-mkconfig - o /boot/grub2/grub.cfg

Restart the system after making changes

# reboot

Then check whether it takes effect

# cat /sys/module/usbcore/parameters/autosuspend
-1
