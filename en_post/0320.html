Copy files between Linux servers

📅 December 13, 2018
📖 1 min read
👁️ 1232 views

There are several ways to copy files between Linux servers:

1 If it is a scheduled task, you can use rsync

2 If you are logging in based on ssh, you can use scp. The advantage is that you can copy from remote to remote. The disadvantage is that you need an account and password.

upload: scp $local_file $remote_username@$remote_ip:$remote_folder

download: scp $remote_username@$remote_ip:$remote_file $local_folder

3. If you only transfer files temporarily and have logged in to two servers, there is a simpler way, you can use nc

Receiving server A: nc -l $receive_port > $file_name
Sending server B: nc $receive_ip $receive_port < $file_name

You can copy the $file_name file on the server to server A;
For example:

1.1.1.1: nc -l 8888 > test.log
1.1.1.2: nc 1.1.1.1 8888 < test.log

Copy test.log on 1.1.1.2 to 1.1.1.1

Want to copy a directory? Also very simple:

Receiving server A: nc -l $receive_port |tar -zxvf -
Sending server B: tar -zcvf - $dir_name |nc $receive_ip $receive_port
