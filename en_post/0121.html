It can be found that catalina.out is not output when running (exec starts Java directly), but catalina.out is output only when starting (nohup starts Java in the background);

 

To output catalina.out, one is tee and the other is redirection. The latter script is as follows:

# cat start.sh
#!/bin/sh

/usr/local/tomcat/bin/catalina.sh run >> /usr/local/tomcat/logs/catalina.out 2>&1

Change the startup command to

$ docker run - d - p 8080:8080 - v /dir/start.sh:/usr/local/tomcat/start.sh tomcat:9 sh /usr/local/tomcat/start.sh

That’s it
