Running in the background

📅 January 14, 2019
📖 1 min read
👁️ 345 views

Linux servers are usually logged in remotely. When executing commands or scripts, if the connection is disconnected (when the execution time is long or the network is unstable), then the process will be gone. At this time, you can only reconnect and re-execute. In this case, you can use background execution:

1 nohup

Order

nohup $command $args &

At this time, a nohup.out file will be generated. The content is the console output of the command execution. You can also redirect it to another file yourself:

nohup $command $args 1>test.log 2>&1 &

2 screen

Install

yum install screen

For detailed session parameters, see

screen - h

 

Here are some commonly used parameters:

 

List all current sessions

screen - list

Create new session

screen - S $session_name

After entering the session, execute any command, and then you can directly close the connection, or temporarily exit the current session (you can re-enter after temporary exit). The temporary exit command is:

Ctrl+A d

kill current session (permanent exit) command:

Ctrl+A k

Re-enter the session

screen - r $session_name

Note that the re-entered session must be in the detached state. If it is in the attached state, it must be detached first:

screen - d $session_name

 

If an error occurs when executing screen

Cannot open your terminal ‘/dev/pts/0’ – please check.

Just execute it first

script /dev/null

3 Tmux

Three concepts: session/window/pane, a session has multiple Windows, and a window has multiple panes.

help

After entering tmux

Ctrl+d ? (show help for all commands)
Exc or q (leave help)

3.1 session related

tmux ls (show all sessions)

tmux new - s myname (create a new session, named myname)

Ctrl+d or exit (exit the current session)

Ctrl+b d or tmux detach (detach the current session and leave temporarily)

tmux a (return to the last session)

tmux a - t myname (returns the session named myname)

tmux attach - t myname 

tmux kill-session - t myname (close the session named myname)

tmux rename - t myname1 myname2 (rename the session named myname1 to myname2)

Ctrl+b s (display all sessions, you can use 0-9 to switch)

tmux switch - t myname (switch to the session named myname)

Ctrl+b $ (rename current session)

3.2 window related

Ctrl+b c (create new window)

Ctrl+b n (switch to next window)

Ctrl+b p (switch to the previous window)

Ctrl+b 0-9 (switch to the specified window)

Ctrl+b, (rename current window)

Ctrl+b w (show all Windows)

Ctrl+b & (Close the current window)

3.3 pane related

Ctrl+b % (split pane vertically)

 tmux split-window

Ctrl+b " (split pane horizontally)

tmux split-window - h


Ctrl+b q (display the number of each panel, directly enter the numeric keys to select the panel when the number is displayed)

Ctrl+b Left|Right|Up|Down (switch cursor between panes)

tmux select-pane - L|R|U|D 

Ctrl+b ; (return to previous pane)

Ctrl+b o (switch to next pane)


Ctrl+b x (close current pane)

Ctrl+b space (re-adjust the layout of all panes)

Ctrl+b z (Adjust the current pane to full screen, and then adjust it back to the original size)

Ctrl+b t (current pane display time)

Ctrl+b Ctrl+o (rotate all panes counterclockwise)

tmux resize-pane - L|R|U|D (resize the current pane)

 

Ctrl+b PageUp|PageDown (page up and down)

q (exit page turning)

 

Ctrl+b [ (Enter copy mode)

q (exit copy mode)

 3.4 Configuration file

Modify configuration

# vi ~/.tmux.conf

setw - g mode-keys vi

set - g default-command /bin/zsh

set - g default-terminal "screen-256color"

set - g pane-active-border-fg black                                                                                                    

set - g pane-active-border-bg red

Effective configuration

# tmux (enter tmux)

Ctrl+b : source-file ~/.tmux.conf

or

# tmux source ~/.tmux.conf
