Docker 3 - Build a private warehouse

📅 February 13, 2019
📖 1 min read
👁️ 388 views

 

Download and start the registry

$ docker pull registry
$ docker run --name my_registry - d - p 5000:5000 - v /var/lib/registry:/var/lib/registry registry

Download Nginx from the official repository and push it to the private repository

$ docker pull nginx
$ docker tag nginx localhost:5000/mynginx
$ docker push localhost:5000/mynginx

push error

The push refers to repository [localhost:5000/nginx]
Get https://localhost:5000/v2/: http: server gave HTTP response to HTTPS client

Solution

$ echo '{ "insecure-registries":["localhost:5000"] }' > /etc/docker/daemon.json
$ service docker restart

Early Docker versions (1.10 and before) do not support insecure-registries and need to be changed to

# vi /etc/sysconfig/docker
OPTIONS='--selinux-enabled --insecure-registry=localhost:5000 --log-driver=journald'

Just push again

$ curl http://localhost:5000/v2/_catalog
{"repositories":["mynginx"]}
