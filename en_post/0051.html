Adjust DataNode memory (Java Heap Size of DataNode in Bytes) and solve the problem

Summary: Insufficient memory in the DataNode causes gc, which in turn causes some queries in Impala queries (queries that use data on the DataNode) to get stuck, which in turn causes a large amount of Impala memory to be occupied, which in turn causes Impala query errors to report that there is insufficient memory.
