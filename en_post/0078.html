MySQL Error When Started with Docker

📅 December 29, 2019
📖 1 min read
👁️ 526 views

docker starts MySQL and restarts repeatedly, passing

# docker logs $container_id

View the log as follows:

chown: cannot read directory '/var/lib/mysql/': Permission denied

However, there was no problem in confirming the directory permissions. Even if chmod 777 was used, the same error was reported. Later, it was found that it was a seLinux problem.

View status

# getenforce

Temporarily disabled

# setenforce 0

Permanently disabled

# vi /etc/selinux/config

# SELINUX= can take one of these three values:
# enforcing - SELinux security policy is enforced.
# permissive - SELinux prints warnings instead of enforcing.
# disabled - No SELinux policy is loaded.
SELINUX=disable

After disabling, docker starts MySQL normally
