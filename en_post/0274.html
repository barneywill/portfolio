1 rz sz

Install

yum install - y lrzsz

upload

rz, dialog box operation

download

sz $filename

Note: rz cannot upload files larger than 4g. At this time, you can change to scp or sftp to upload, where the sftp url is: sftp://user:passwd@host:22

2 scp

Install

yum install scp

upload

scp /local_dir/filename user@server_ip:/remote/path 

download

scp user@server_ip:/remote/path/filename /local_dir

 

3 windows pscp

pscp /local_dir/filename user@server_ip:/remote/path
