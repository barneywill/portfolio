SSH Tunneling/Port Forwarding

📅 January 28, 2019
📖 1 min read
👁️ 1790 views

Format

ssh - L <local port>:<remote host>:<remote port> <SSH servername>

Example

# ssh - L 3307:$server2:3306 user@$server1

The effect achieved is to use user to log in to $server1 and then establish a tunnel from the local 3307 port to the remote $server2:3306 port, and access the remote $server2:3306 port by accessing the local 3307 port. The premise is that $server1 can access the $server2:3306 port;
