Kudu reports an error unable to find SASL plugin: PLAIN

📅 April 30, 2019
📖 1 min read
👁️ 1522 views

After Kudu is installed, it does not run normally. No tserver can be found in the master. Checking the tserver log shows that there are many errors:

Failed to heartbeat to master:7051: Invalid argument: Failed to ping master at master:7051: Client connection negotiation failed: client connection to master:7051: unable to find SASL plugin: PLAIN

Solution:

yum install gcc python-devel
yum install cyrus-sasl*

Then restart Kudu. If there is Impala, you also need to restart it;
