securecrt connection automatically disconnected

📅 January 14, 2019
📖 1 min read
👁️ 641 views

securecrt will automatically disconnect if there is no operation for a period of time (xshell does not have this problem). The prompt message is: the semaphore timeout has expired. The solution is:

Options -- Session Options -- Terminal -- Send protocol NO-OP
