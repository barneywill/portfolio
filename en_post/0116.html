Using JVM tool in Docker container

📅 June 15, 2019
📖 3 min read
👁️ 1804 views

Java applications often need to use JVM tools to perform some operations. If the Java application is deployed in a Docker container, how to use the JVM tool?

First, we need to look at the Docker image used.

  • For example, commonly used openjdk images are divided into jdk and jre. Only the jdk version has JVM tools, so you can directly use the jdk version of openjdk;
  • For example, the commonly used tomcat image does not have jdk and jre options. By default, jre is used, so there is no JVM tool. The jdk directory in the tomcat image is as follows:
# ls /usr/lib/jvm/java-1.8-openjdk
bin  jre  lib
# ls /usr/lib/jvm/java-1.8-openjdk/bin
appletviewer  orbd          rmid          tnameserv
java          pack200       rmiregistry   unpack200
keytool       policytool    servertool
# ls /usr/lib/jvm/java-1.8-openjdk/lib
amd64

At this time, you can use the mounting method to mount the jdk file into the container and then execute it. First, you must find the corresponding jdk file. The first step is to find the operating system version of the current container.

 

Several common versions:

Then find the corresponding jdk image according to the operating system version, such as openjdk

openjdk:<version> based on debian
openjdk:<version>-alpine Based on alpine

The tomcat image is based on alpine, so download openjdk:8-jdk-alpine. 8 is the specific jdk version. After downloading, copy the jdk directory.

/usr/lib/jvm/java-1.8-openjdk/

If you want to use JVM tools, there are several ways:

  • Copy files directly to the container;
  • Mount the required files into the container;
  • Mount the jdk directory into the container and directly replace the original jdk directory;

The first two methods only require a few files, one is $JAVA_HOME/lib/tools.jar, and the other is specific JVM tools such as jmap, jstack, jstat, etc. in $JAVA_HOME/bin/. Copy or mount the files to the specified location in the container to use;

The last one is the simplest. All JVM tools can be used after mounting the jdk directory;

# docker exec - it $container_id jstat - gcutil $pid
