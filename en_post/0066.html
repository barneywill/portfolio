Using zsh

📖 1 min read

1. Install zsh

 

# apt-get install zsh (ubuntu)
# yum install zsh (redhat & centos)
# zypper in zsh (opensuse)
# mac comes with it

 

2. Install oh my zsh

$ sh - c "$(curl - fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Official website: https://ohmyz.sh

 

After installation, the .zshrc file and .oh-my-zsh directory will be added to the home directory. Other servers can copy these two directly.

 

3. Install plugin

 

1 zsh-autosuggestions

git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

# vi .zshrc

plugins=( [plugins...] zsh-autosuggestions)

ps:

1 Multiple plugins separated by spaces

2 plugin directory ~/.oh-my-zsh/custom/plugins. After one installation, the plugin directory can be directly synchronized to other servers.

3 After the prompt, use Ctrl+f to automatically complete

4 The default color of the prompt is gray, which may not be obvious under some themes. It can be modified as follows:

vim ~/.oh-my-zsh/custom/plugins/zsh-autosuggestions/zsh-autosuggestions.zsh
typeset - g ZSH_AUTOSUGGEST_HIGHLIGHT_STYLE='fg=yellow'

2 zsh-syntax-highlighting

 

git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting

# vi .zshrc

plugins=( [plugins...] zsh-syntax-highlighting)

5. Modify the default shell

1 When installing oh-my-zsh

Select y at the end of installation

2 chsh command

# chsh - s /bin/zsh

3 Modify passwd file

# vi /etc/passwd

Change a user's last /bin/bash to /bin/zsh
