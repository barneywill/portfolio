It seems to be a Scala version conflict. I went to the Spark download page and found this sentence:

Note that, Spark is pre-built with Scala 2.11 except version 2.4.2, which is pre-built with Scala 2.12.

4) Kudu-Spark changed to scala2.12

spark-2.4.2-bin-hadoop2.6

6) Adopt the official method (change the Kudu version to 1.7.0)

spark-2.4.3-bin-hadoop2.6

# bin/spark-shell --packages org.apache.kudu:kudu-spark2_2.11:1.7.0

same error

It seems that Spark can only use scala2.11+Kudu-spark2_2.11:1.9.0 to connect to Kudu.
