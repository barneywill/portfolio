1 Introduction 

Build great things at any scale

The leading open source automation server, Jenkins provides hundreds of plugins to support building, deploying and automating any project.

Jenkins supports hundreds of plug-ins to support build, deployment and automation;

Jenkins is a self-contained, open source automation server which can be used to automate all sorts of tasks related to building, testing, and delivering or deploying software.

Jenkins can be installed through native system packages, Docker, or even run standalone by any machine with a Java Runtime Environment (JRE) installed.

 

Any company faces project deployment problems, and project deployment abstractly includes: 1) specifying branches and versions; 2) downloading code from the code base; 3) compiling and packaging; 4) publishing to a remote server; 5) restarting the application; 6) rolling back;

What is published to the remote server can be a jar, war, docker image or folder as needed;

Jenkins allows you to accomplish all the above through plug-ins, configurations, and scripts;

 

2. Installation

sudo wget -O /etc/yum.repos.d/jenkins.repo https://pkg.jenkins.io/redhat-stable/jenkins.repo
sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io.key
yum install jenkins

start up

systemctl start jenkins
systemctl enable jenkins
systemctl status jenkins

Access after startup

http://localhost:8080

If there is a conflict with the default port 8080, you can modify it.

vi /etc/init.d/jenkins
export JENKINS_PORT=8080

First time login random password is here

/var/lib/jenkins/secrets/initialAdminPassword

Just follow the wizard;

Directory structure

The jenkins directory is located at

/var/lib/jenkins

The workspace directory is located at

/var/lib/jenkins/workspace

The job directory is

/var/lib/jenkins/workspace/${JOB_NAME}

Code downloading, compilation and packaging are all in the job directory, such as the target directory;
