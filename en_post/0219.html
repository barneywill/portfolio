MySQL 3 -MySQL delete historical binlog

📅 February 17, 2019
📖 1 min read
👁️ 600 views

After MySQL opens binlog, it will create a binlog file under /var/lib/MySQL. If you delete it manually, an error will be reported next time MySQL starts:

mysqld: File './master-bin.000001' not found (Errcode: 2 - No such file or directory)
2019-02-16T17:00:08.484461Z 0 [ERROR] Failed to open log (file './master-bin.000001', errno 2)
2019-02-16T17:00:08.484464Z 0 [ERROR] Could not open log file

The correct way to delete is:

mysql> show binary logs;
+-------------------+------------+
| Log_name | File_size |
+-------------------+------------+
| master-bin.000027 | 43442 |
| master-bin.000028 | 7573 |
| master-bin.000029 | 371919 |
+-------------------+------------+
29 rows in set (0.00 sec)

mysql> purge binary logs to 'master-bin.000029';
Query OK, 0 rows affected, 10 warnings (0.18 sec)

mysql> show binary logs;
+-------------------+-----------+
| Log_name | File_size |
+-------------------+-----------+
| master-bin.000029 | 696322 |
+-------------------+-----------+
1 row in set (0.00 sec)

You can also configure the expiration time in the configuration file.

# vi /etc/mysql/my.cnf
expire_logs_days = 7

mysql> reset master;
