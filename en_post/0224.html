DataNode startup error: port 50020 is occupied

📅 February 15, 2019
📖 1 min read
👁️ 1109 views

There is a DataNode in the cluster that keeps starting and reports the following error:

java.net.BindException: Problem binding to [$server1:50020] java.net.BindException: Address already in use; For more details see: http://wiki.apache.org/hadoop/BindException

Check whether the port is occupied

# netstat - tnlp|grep 50020

It is found that there is no process listening on port 50020. It is strange. It may also be connected to other servers from port 50020 of this machine. Check again (either through netstat or lsof).

# netstat - nat|grep 50020
tcp 0 0 $server1:50020 $server2:7050 ESTABLISHED 8578/kudu-tserver

or

# lsof - i:50020
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
kudu-tser 8578 kudu 22u IPv4 4295504 0t0 TCP cdp-test-server-02.bj:50020->cdp-test-server-04.bj:7050 (ESTABLISHED)

It turns out that it was caused by a random port occupation by Kudu. Just restart the tserver;
