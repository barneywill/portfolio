sudo allows users to execute commands as other users (such as root), such as switching users, executing commands, reading and writing files, etc.;

Configuration

sudo is configured in:/etc/sudoers

## Sudoers allows particular users to run various commands as
## the root user, without needing the root password.
##
## Examples are provided at the bottom of the file for collections
## of related commands, which can then be delegated out to particular
## users or groups.
##
## This file must be edited with the 'visudo' command.
...
## Next comes the main part: which users can run what software on
## which machines (the sudoers file can be shared between multiple
## systems).
## Syntax:
##
## user MACHINE=COMMANDS
##
## The COMMANDS section may have other options added to it.
##
## Allow root to run any commands anywhere
root ALL=(ALL) ALL
...
## Read drop-in files from /etc/sudoers.d (the # here does not mean a comment)
#includedir /etc/sudoers.d

Three points can be seen from this configuration file:

  • The configuration format (user MACHINE=COMMANDS) and examples (near the end), such as root permissions;
  • /etc/sudoers.d/* The files under this directory will also be loaded, so that different categories of permission configurations can be separated into different files;
  • Use visudo to edit, you can also use vi or vim to edit, but visudo will check before saving. If there is a problem with the configuration, an error will be reported. Directly saving the wrong configuration may lead to unpredictable consequences, so do not try it;

Options are:
(e)dit sudoers file again
e(x)it without saving changes to sudoers file
(Q)uit and save changes to sudoers file (DANGER!)

What now?

Common scenarios

1 Switch users

username ALL=(root) NOPASSWD: /bin/su - targetuser

Allow username to switch to targetuser

%groupname ALL=(root) NOPASSWD: /bin/su - targetuser

Allow users in groupname to switch to targetuser

2 Execute the command

username ALL=(root) NOPASSWD: /usr/sbin/iptables

Allow username to execute iptables commands
