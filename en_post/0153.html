Execute Impala through Shell in Oozie

📅 April 01, 2019
📖 2 min read
👁️ 1282 views

Impala is executed through the Shell in Oozie. The script is as follows:

$ cat test_impala.sh
#!/bin/sh
/usr/bin/kinit - kt /tmp/impala.keytab impala/server04
/usr/bin/impala-shell - i server04:21000 - q 'show databases'

Directly executing the Shell script is normal, but executing it in Oozie reports an error:

The following error occurred while trying to extract file(s) to the Python egg
cache:

  [Errno 13] Permission denied: '/home/.python-eggs'

The Python egg cache directory is currently set to:

  /home/.python-eggs

Perhaps your account does not have write access to this directory?  You can
change the cache directory by setting the PYTHON_EGG_CACHE environment
variable to point to an accessible directory.

Failing Oozie Launcher, Main class [org.apache.oozie.action.hadoop.ShellMain], exit code [1]

Follow the prompts to modify PYTHON_EGG_CACHE

$ cat test_impala.sh
#!/bin/sh
export PYTHON_EGG_CACHE=/tmp/.python-eggs
/usr/bin/kinit - kt /tmp/impala.keytab impala/server04
/usr/bin/impala-shell - i server04:21000 - q 'show databases'

In addition, you can also connect through beeline, so there is no problem with Python.
