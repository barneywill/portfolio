📅 January 15, 2019

 The first step in Ambari installation is to enter the cluster name. When you click next, the page gets stuck, as shown below:

It was noticed that one of the interface request results was abnormal. http://Ambari.server:8080/API/v1/version_definitions reproduced as follows:

Following up on the code, we found that the corresponding js code is:

ambari-web/app/controllers/installer.js

  /**
   * query every stack names from server
   * @return {Array}
   */
  loadStacksVersions: function () {
    var requests = [];
    const dfd = $.Deferred();
    this.get('stackNames').forEach(function (stackName) {
      requests.push(App.ajax.send({
        name: 'wizard.stacks_versions_definitions',
        sender: this,
        data: {
          stackName: stackName,
          dfd: dfd
        },
        success: 'loadStacksVersionsDefinitionsSuccessCallback',
        error: 'loadStacksVersionsErrorCallback'
      }));
    }, this);
    this.set('loadStacksRequestsCounter', requests.length);
    return dfd.promise();
  },

This code needs to access all stack versions, but the server returns empty, so it keeps getting stuck.

You can see that isActive takes the value from StackMetainfoXml

org.apache.ambari.server.state.stack.StackMetainfoXml

The metainfo.XML corresponding to this class is

/var/lib/ambari-server/resources/stacks/HDP/$version/metainfo.xml 

cat /var/lib/ambari-server/resources/stacks/HDP/2.6/metainfo.xml

<metainfo>

  <versions>

    <active>false</active>

  </versions>

  <extends>2.5</extends>

  <minJdk>1.7</minJdk>

  <maxJdk>1.8</maxJdk>

</metainfo>

Check metainfo.XML and find that after the installation is completed, active in each version of metainfo.XML defaults to false;

Change active to true, and then restart Ambari-server. If the problem is solved after restarting, congratulations. If you still have problems, please continue reading:

Try to register vdf manually

curl -v -k -u admin:admin -H "X-Requested-By:ambari" -X POST http://ambari.server:8080/api/v1/version_definitions -d '{"VersionDefinition": {"version_url":"http://s3.amazonaws.com/dev.hortonworks.com/HDP/centos7/2.x/BUILDS/2.6.5.0-292/HDP-2.6.5.0-292.xml"}}'

Various versions of vdf can be found here: http://s3.amazonaws.com/dev.hortonworks.com/HDP/hdp_urlinfo.JSON
