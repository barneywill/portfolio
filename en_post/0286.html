1. Scenario analysis

Positioning analysis is widely used, such as outdoor base station positioning, indoor Bluetooth beacon positioning, indoor wifi probe positioning, etc. The implementation method is three-point positioning Trilateration

ideal situation

 

This ideal situation requires three base stations to collect "accurate" distance information at the same time.

actual situation

  • The three base stations collect data at separate times;
  • The distance at which the data was collected is inaccurate;

The solution is:

  • Increasing the number of base stations means increasing the density and quantity of collected data;
  • Instead of using data from one point in time, data from a time period is used for calculation. For example, there may be only data from one base station within 5 seconds, but there may be data from more than three base stations within 30 seconds;
  • Within the error range, mathematical methods are used to iteratively converge and find the coordinates of the most probable unknown point in terms of probability;

2. Problem abstraction

Known conditions

  • Position coordinates of n points: (x1, y1), (x2, y2), (x3, y3), ..., (xn, yn)
  • Distance from unknown point to n points: d1, d2, d3, ..., dn

Solve

  • Unknown point position coordinates (x, y)

equation

 

solution

The above equation is n quadratic equations,

1) First try to reduce the degree, and subtract the i-th equation from the i-1 equation in the system of equations one by one to obtain a new equation, so that n quadratic equations are converted into n-1 linear equations,

2) After obtaining n-1 linear equations (linear equations), the problem is converted into a linear regression problem:

That is, there are n observation points (x1, y1), (x2, y2), ..., (xn, yn) in the plane. You need to find a straight line Y=aX+b. Calculate constant a and constant b to minimize the sum of squares of the distance (error) between the n observation points and the straight line (note that the coordinates of the unknown point in the original problem are the constant a and constant b here);

 

The one-variable linear regression model can use the least squares method (least squares method) to obtain the optimal solution, that is, the least squares solution; for details on the least squares method, see:https://www.cnblogs.com/barneywill/p/10217349.html

scala

 

  /**
    * @param datas Array(x_coordinates, y_coordinates, distance)
    * @return (x_coordinates, y_coordinates)
    */
  def detect(datas : Array[(Double, Double, Double)]) : (Double, Double) = {
    if (datas == null || datas.isEmpty) (0, 0)
    else if (datas.length == 1) return (datas.head._1, datas.head._2)
    else if (datas.length == 2) return ((datas.head._1 + datas.last._1) / 2, (datas.head._2 + datas.last._2) / 2)
    else {
      var data = Array[Array[Double]]()
      //X + (y_1 - y_i)/(x_1 - x_i)Y = (sq(d_i) - sq(d_1) + sq(x_1) + sq(y_1) - sq(x_i) - sq(y_i))/2(x_1 - x_i)
      for (i <- 1 to (datas.length - 1)) data = data :+ Array((datas.head._2 - datas.apply(i)._2) / (datas.head._1 - datas.apply(i)._1), (Math.pow(datas.apply(i)._3, 2) - Math.pow(datas.head._3, 2) + Math.pow(datas.head._1, 2) + Math.pow(datas.head._2, 2) - Math.pow(datas.apply(i)._1, 2) - Math.pow(datas.apply(i)._2, 2))  / 2 / (datas.head._1 - datas.apply(i)._1))
      val regression = new SimpleRegression
      regression.addData(data)
      (regression.getIntercept, regression.getSlope)
    }
  }
