Apache Oozie Workflow Scheduler for Hadoop

Workflow scheduler for Hadoop ecosystem

Overview

Oozie is a workflow scheduler system to manage Apache Hadoop jobs.

Oozie Workflow jobs are Directed Acyclical Graphs (DAGs) of actions.

Oozie Coordinator jobs are recurrent Oozie Workflow jobs triggered by time (frequency) and data availability.

Oozie is integrated with the rest of the Hadoop stack supporting several types of Hadoop jobs out of the box (such as Java map-reduce, Streaming map-reduce, Pig, Hive, Sqoop and Distcp) as well as system specific jobs (such as Java programs and shell scripts).

Oozie is a scalable, reliable and extensible system.

3 Database table structure

 

 

wf_jobs: Workflow instance

wf_actions: task instance

coord_jobs: scheduling instance

coord_actions: Scheduling task instance

4 concepts

l Control Node: The start and end of the workflow and the node that determines the execution path of the Workflow (start, end, kill, decision, fork/join)

l Action Node: Computing tasks executed by workflow, supported types include (HDFS, MapReduce, Java, Shell, SSH, Pig, Hive, Email, Sub-Workflow, Sqoop, Distcp), that isTask

l Workflow: A workflow composed of Control Node and a series of Action Node, that is,Workflow

l Coordinator: Trigger workflow based on specified Cron information, that isScheduling

l Bundle: Manage Coordinator tasks in batches according to groups to achieve centralized start and stop.

5 distributed

Some internal tasks can only be started once. In the single-server environment Oozie, this is guaranteed by MemoryLocksService. In the multi-server environment Oozie, it is guaranteed by ZKLocksService. To enable ZK, you need to enable some services:

org.apache.oozie.service.ZKLocksService,

org.apache.oozie.service.ZKXLogStreamingService,

org.apache.oozie.service.ZKJobsConcurrencyService,

org.apache.oozie.service.ZKUUIDService

At the same time, you need to configure Oozie.ZooKeeper.connection.string
