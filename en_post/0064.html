Using Emacs

📅 June 25, 2020
📖 1 min read
👁️ 272 views

Official website:https://www.gnu.org/software/emacs/

An extensible, customizable, free/libre text editor — and more.

1 installation

# yum install emacs

# apt-get install emacs

# zypper in emacs 

Windows and mac can also be downloaded and installed

Two configuration

Configuration file: ~/.emacs

Three shortcut keys

1 File related operations

Ctrl+x Ctrl+f (open file)

Ctrl+x Ctrl+s (save)

Ctrl+x Ctrl+w (write file)

Ctrl+x Ctrl+v (close file and open)

Ctrl+x k (close file)

Ctrl+x b (switch to next file)

Ctrl+x Ctrl+b (show list of all files)

Ctrl+x Ctrl+c (exit emacs)

2 Window related operations

Ctrl+x 2 (split window horizontally)

Ctrl+x 3 (split window vertically)

Ctrl+x 0 (Close current window)

Ctrl+x 1 (Close other windows)

Ctrl+x o (switch window)

3 Move cursor

Ctrl+f (next character)

Ctrl+b (previous character)

Ctrl+n (next line)

Ctrl+p (previous line)

Ctrl+a (beginning of line)

Ctrl+e (end of line)

Cmd+f (next word)

Cmd+b (previous word)

Cmd+< (file header)

Cmd+> (end of file)

Ctrl+v (next page)

Cmd+v (previous page)

4 search

Ctrl+s (search down)

Ctrl+r (search up)

5 Delete

Ctrl+h

Ctrl+d

Ctrl+k
