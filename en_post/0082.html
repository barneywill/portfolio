Expanding Disk Capacity on an Alibaba Cloud Host

📅 December 15, 2019
📖 1 min read
👁️ 418 views

After console operation disk expansion

1 installation

# yum install cloud-utils-growpart
# yum install xfsprogs

2 View all disks

# fdisk - l

3 Check the partition size

# df - h

4 disk expansion

# growpart /dev/vda 1

Format: growpart <DeviceName> <PartionNumber>

5 partition expansion

# resize2fs /dev/vda1

Format: resize2fs <PartitionName>

6 Confirm

# df - h

 

Reference: https://help.aliyun.com/document_detail/111738.html?spm=a2c4g.11186623.2.30.4ad77f67UvYpVl#concept-ocb-htw-dhb
