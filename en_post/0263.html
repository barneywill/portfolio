Ambari metrics collector built-in standalone HBase fails to start

📅 January 17, 2019
📖 1 min read
👁️ 5040 views

The built-in HBase directory of Ambari metrics collector is located at

/usr/lib/ams-hbase

The configuration is located at

/etc/ams-hbase/conf

Start via Ruby

/usr/lib/ams-hbase/bin/hirb.rb

The actual startup command is

/usr/lib/ams-hbase/bin/hbase-daemon.sh --config /etc/ams-hbase/conf foreground_start master

However, after a while of startup, an error message appears:
