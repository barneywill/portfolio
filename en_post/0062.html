Changing the Terminal Theme on macOS

📅 June 28, 2020
📖 1 min read
👁️ 382 views

download

git clone https://github.com/mbadolato/iTerm2-Color-Schemes.git

After the download is complete, the iTerm2-Color-Schemes/terminal directory is full of themes.

Configuration

Terminal-Preferences-Profiles

On the left are all current topics

Any theme downloaded by import will appear in the theme list. Double-clicking the theme will open a new window to apply the theme. Clicking default in the lower right corner will set the theme as the default.
