1. Scenario analysis

There are many application scenarios for user behavior analysis, such as online website visit statistics and offline passenger flow analysis (such as image and face recognition, wifi probes, etc.). There are several core indicators:

PV | UV | SD | SC

Indicator description:

PV (Page View): Website views or visits to shopping mall stores
UV (Unique Visitor): Number of unique visitors, that is, the number of people after removing duplicates
SD (Session Duration): single session dwell time
SC (Session Count): Number of sessions

 

The raw data for user behavior analysis is usually a series of time-discrete data, such as website access records: the user visited a web page at one point in time, and then visited the next web page at the next point in time;

 These raw data can be abstracted as:

User | Timestamp | Target

That is, what target the user visited at what point in time;

 

Statistics of PV and UV are relatively simple, but based on time discrete data, the two indicators SD and SC need to be calculated. A common way is to set an expiration time threshold. If the time interval between two visits by a user exceeds the threshold, it is considered to be two sessions; then the earliest and latest data of all data in a session are taken to count the session duration;

There is also the problem of data disorder during actual processing, especially in real-time calculations. Have you figured out how to deal with it?

The easy way to think of is to make a group first and then sort all the timestamps and then traverse to count the SD and SC. However, this method takes up a lot of memory, has slightly poor performance, and can only be used in offline calculations.

 

Three code implementation

The Scala implementation is given below to witness the power of Scala:

Scala core code (one step foldLeft)

scala

  val expireInSecond = 300
  def mergeTimeArray(arr1 : ArrayBuffer[(Long, Long)], arr2 : ArrayBuffer[(Long, Long)]) : ArrayBuffer[(Long, Long)] = {
    if (arr1.head._1.equals(0l)) arr2
    else if (arr2.head._1.equals(0l)) arr1
    else (arr1 ++ arr2).sortBy(_._1).foldLeft(ArrayBuffer[(Long, Long)]())((result, item) => if (!result.isEmpty && result.last._2 + expireInSecond >= item._1) {result.update(result.length - 1, (result.last._1, math.max(result.last._2, item._2))); result} else result += item)
  }

Spark core code (2-step map 1-step aggregateByKey)

scala

  /**
    * @param data (user, timestamp, target)
    * @return (user, target, session_count, session_duration)
    */
  def process(data : RDD[(String, Long, String)]) : RDD[(String, String, Integer, Double)] = {
    //((user, target), timestamp)
    data.map(item => ((item._1, item._3), item._2))
      //((user, target), Array[(startTime, endTime)])
      .aggregateByKey(ArrayBuffer((0l, 0l)))((result : ArrayBuffer[(Long, Long)], timestamp: Long) => mergeTimeArray(result, ArrayBuffer((timestamp, timestamp))), (result1 : ArrayBuffer[(Long, Long)], result2 : ArrayBuffer[(Long, Long)]) => mergeTimeArray(result1, result2))
      //(user, target, session_count, session_duration)
      .map(item => (item._1._1, item._1._2, item._2.length, item._2.foldLeft(0l)((result, item) => result + (item._2 - item._1)).toDouble / item._2.length))
  }
