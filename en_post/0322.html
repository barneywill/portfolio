YARN important configuration YARN.nodemanager.local-dirs

📅 December 13, 2018
📖 1 min read
👁️ 8732 views

There is a more important configuration YARN.nodemanager.local-dirs in YARN. If the configuration is not good, many problems will occur in the cluster when running in a saturated state:
1 The default configuration is ${hadoop.tmp.dir}/nm-local-dir. The system disk is usually only a few hundred G. If configured here, errors of insufficient disk space will often be reported;
2 Configure one of the data disks, such as /data0/. This data disk will often become unresponsive or directly broken;
3 The correct configuration is to configure all data disks, usually 12. In fact, the description of YARN is very clear.

<property>

  <description>List of directories to store localized files in. An

    application's localized file directory will be found in:

    ${yarn.nodemanager.local-dirs}/usercache/${user}/appcache/application_${appid}.

    Individual containers' work directories, called container_${contid}, will

    be subdirectories of this.

 </description>

  <name>yarn.nodemanager.local-dirs</name>

  <value>${hadoop.tmp.dir}/nm-local-dir</value>

</property>

 

  <property>

    <name>hadoop.tmp.dir</name>

    <value>/tmp/hadoop-tmp</value>

    <description>A base for other temporary directories.</description>

  </property>
