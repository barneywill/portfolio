1. Compilation

There are two ways to compile doris, one is docker compilation, and the other is direct bare metal compilation. It is recommended to use docker compilation, which can avoid a large number of environmental dependency problems.

Docker Compilation

1 Install docker

yum install docker
systemctl start docker
systemctl enable docker
docker pull apachedoris/doris-dev:build-env-1.2

2 Download source code

wget https://mirrors.bfsu.edu.cn/apache/incubator/doris/0.13.0-incubating/apache-doris-0.13.0-incubating-src.tar.gz
tar xvf apache-doris-0.13.0-incubating-src.tar.gz

3 Start the container

docker run - it - v /root/.m2:/root/.m2 - v /path/to/apache-doris-0.13.0-incubating-src:/root/apache-doris-0.13.0-incubating-src apachedoris/doris-dev:build-env-1.2

Two directory mappings need to be done, one is the maven repository directory, and the other is the doris source code directory to avoid the loss of previously downloaded or compiled content after the container hangs.

4 Compile doris

cd /root/apache-doris-0.13.0-incubating-src
sh - x build.sh

After compilation, it is output to the output directory. There are three subdirectories: be, fe, and udf. You only need to copy the output directory to other servers.

Bare metal compilation

1 preparation

jdk8+
maven

sudo yum groupinstall 'Development Tools' && sudo yum install maven cmake byacc flex automake libtool bison binutils-devel zip unzip ncurses-devel curl git wget python2 glibc-static libstdc++-static java-1.8.0-openjdk

Among them: gcc defaults to 4.8.5 on CentOS7, cmake defaults to 2.8.12

2 Upgrade GCC

yum install gcc-c++
wget http://ftp.tsukuba.wide.ad.jp/software/gcc/releases/gcc-7.3.0/gcc-7.3.0.tar.gz
tar zxvf tar zxvf gcc-7.3.0.tar.gz
cd gcc-7.3.0
yum install lbzip2
./contrib/download_prerequisites
mkdir build
cd build/
../configure --enable-checking=release --enable-languages=c,c++ --disable-multilib
make
make install

3 Upgrade CMAKE

wget https://cmake.org/files/v3.6/cmake-3.6.2.tar.gz
tar xvf cmake-3.6.2.tar.gz && cd cmake-3.6.2/
./bootstrap
gmake
gmake install
mv /usr/bin/cmake /usr/bin/cmake.bak
ln - s /usr/local/bin/cmake /usr/bin/

4 compile

sh - x build.sh

2 start

1 Start FE

cd output/fe
mkdir doris-meta
bin/start_fe.sh --daemon

The log is in the log directory

Notice:

  • The default port 8030 may conflict with YARN's resourcemanager
  • After startup, check whether the IP of the bound port of fe is correct. If the binding IP is wrong (for example, getting the docker IP after installing docker), be cannot connect to fe. You need to configure priority_networks in fe.conf to the correct network segment.

priority_networks=192.168.1.0/24

2 Start BE

cd output/be
mkdir /path/to/storage
vim conf/be.conf
bin/start_be.sh --daemon

The log is in the log directory

Notice:

  • The default port 8040 may conflict with YARN’s nodemanager
  • If be fails to start, there may generally be two reasons: one is that the port is occupied, and the other is limit. Check according to the log, such as reporting an error.
    Doris Be http service did not start correctly. exiting.
    It is because the port is occupied that the web startup fails.

Modify limit

Temporary modification

limit - n 65535

Permanent modification

vim /etc/security/limit.conf
*               hard    nofile             65535
*               soft    nofile             65535

3 Start Broker

cd fs_brokers/apache_hdfs_broker/output/apache_hdfs_broker
bin/start_broker.sh --daemon

Three uses

1 FE web access

http://fe_server:8030

Notice:

  • The port is http_port
  • The default account is root and the password is empty.

2 FE command access

mysql - P9030 - uroot
show proc '/frontends';

Notice:

  • The port is query_port

3 Add or delete FE

alter system add follower '$host:$port';
show proc '/frontends';

4 Add or delete BE

alter system add backend '$host:$port';
alter system dropp backend '$host:$port';
show proc '/backends';

Notice:

  • The default port is 9050, which is heartbeat_service_port

5 Add or delete Broker

alter system add broker $broker_name '$host:$port';
show proc '/brokers';

Notice:

  • The default port is 8000, which is broker ipc_port

Hive data import

create database test;
CREATE TABLE test.test_user_doris
(
  `id` varchar(128) , 
  `name` varchar(128) , 
  `country` varchar(128) , 
  `province` varchar(128) , 
  `city` varchar(128) ,  
  `order_count` int SUM
)
AGGREGATE KEY(id, name, country, province, city)
DISTRIBUTED BY HASH(id) BUCKETS 10
PROPERTIES("replication_num" = "3");

LOAD LABEL load_test_user_doris
(
    DATA INFILE("hdfs://nameservice1/user/hive/warehouse/test.db/test_user/*")
    INTO TABLE `test_user_doris`
    FORMAT as "parquet"
)
WITH BROKER $broker_name 
(
    "dfs.nameservices" = "nameservice1",
    "dfs.ha.namenodes.nameservice1" = "namenode1,namenode2",
    "dfs.namenode.rpc-address.nameservice1.namenode1" = "nn1:8020",
    "dfs.namenode.rpc-address.nameservice1.namenode2" = "nn2:8020"
)
PROPERTIES
(
    "timeout"="36000",
    "max_filter_ratio"="0.1"
);
