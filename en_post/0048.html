CentOS Boots into Emergency Mode

📅 December 04, 2020
📖 1 min read
👁️ 1141 views

CentOS boots into emergency mode. After logging in to the root account, you can pass

journalctl - xb

Check the log. There will be specific error information in it. There are two common errors:
1) If you have changed /etc/fstab before restarting, there may be a problem with the configuration. Recheck the file and then try again.

reboot

Restart and the problem is solved;
2) If you were fORCed to power off and shut down before restarting, it may be that some content was not written from the memory to the disk in time due to the shutdown, causing problems. Find the problematic partition from the log, temporarily comment out the partition in /etc/fstab, and then restart

reboot

Restart and you can temporarily enter the system;
To repair the problematic partition, you need to operate according to different file systems. For example, to repair the xfs file system, use

xfs_repair /dev/sda1

If an error is reported, add the -L parameter and some data may be lost.

xfs_repair - L /dev/sda1

It is better than losing everything. After repairing, restore /etc/fstab and then restart.
