yum offline environment installation software

📅 February 15, 2019
📖 1 min read
👁️ 540 views

First check the system version number, and then select one to download from CentOS-7-x86_64-DVD-1708.iso and CentOS-7-x86_64-Everything-1708.iso according to the version number. Here is 7.4.1708

# cat /etc/redhat-release
CentOS Linux release 7.4.1708 (Core)

# wget http://vault.centos.org/7.4.1708/isos/x86_64/CentOS-7-x86_64-DVD-1708.iso
# mkdir /mnt/centos7
# mount - o loop,ro CentOS-7-x86_64-DVD-1708.iso /mnt/centos7

Back up the previous repo

# mkdir /etc/yum.repo.d/bak
# mv /etc/yum.repo.d/*.repo /etc/yum.repo.d/bak/

 

Choose one of the following

1 Directly use iso as source

# vi /etc/yum.repos.d/centos7_iso.repo
[centos7-Server]
name=ServerFault Answer
baseurl=file:///mnt/centos7
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
gpgcheck=1

2 Copy the iso to a local folder as the source

# cp - a /mnt/centos7/ /yum/

# vi /etc/yum.repos.d/centos7_localhost.repo
[centos7-Server]
name=ServerFault Answer
baseurl=file:///yum/centos7
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
gpgcheck=1

3 Build Nginx or httpd or ftpd service as a LAN source

# vi /etc/yum.repos.d/centos7_localnetwork.repo
[centos7-Server]
name=ServerFault Answer
baseurl=http://192.168.0.1/
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
gpgcheck=1

The Nginx configuration is as follows (add a location)

location / {
root /yum/centos7;
autoindex on;
}

 

test

# yum repolist
# yum install $anything
