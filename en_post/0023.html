position

Error reports are sporadic and irregular. Check the directory where the error is reported and download the directory for Hive. The configuration is:

hive.downloaded.resources.dir=/disk1/hive/download

The inspection found that the directory does not exist for many nodes in the cluster. It is suspected that there is a problem with the initialization of the server environment, and some nodes are not initialized correctly.
Further inspection revealed that the directory of the same node sometimes exists and sometimes does not exist, ruling out the above suspicion.
The default value of this configuration in Hive is:

hive.downloaded.resources.dir=${system:java.io.tmpdir}/${hive.session.id}_resources

It can be seen that this directory is related to the session and will be deleted every time the session is closed. If the configured path does not have a sessionid, different sessions will affect each other.

DOWNLOADED_RESOURCES_DIR("hive.downloaded.resources.dir",
    "${system:java.io.tmpdir}" + File.separator + "${hive.session.id}_resources",
    "Temporary local directory for added resources in the remote file system."),

Modify the configuration as:

hive.downloaded.resources.dir=/disk1/hive/download/${hive.session.id}_resources

Problem solved.
