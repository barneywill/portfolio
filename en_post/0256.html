Several deployment methods of Hive metastore

📅 January 21, 2019
📖 1 min read
👁️ 1288 views

Hive and other components (such as Spark, Impala, etc.) will depend on Hive metastore, and the dependent configuration file is located in Hive-site.XML

Important configuration of Hive metastore

hive.metastore.warehouse.dir
The default for hive2 and previous versions is /user/Hive/warehouse/. When creating a database or table, the corresponding directory will be created in this directory.

javax.jdo.option.ConnectionURL
javax.jdo.option.ConnectionDriverName
javax.jdo.option.ConnectionUserName
javax.jdo.option.ConnectionPassword
Default is derby

hive.metastore.uris
Default is empty

Hive metastore deployment method

1 All default configurations

The built-in derby library is used, and the HDFS directory is /user/Hive/warehouse/

2 Configure only javax.jdo.option.* related configurations

Use the configured database (such as MySQL), and the HDFS directory is /user/Hive/warehouse/

3 Only configure Hive.metastore.uris

All metadata operations interact through the remote metastore (note that an independent Hive metastore process needs to be started at this time), and the HDFS directory is /user/Hive/warehouse/

ps: Note that 1 and 2 do not require any Hive process, but all 3 methods need to rely on HDFS

Summarize

In summary, when you only need to use Impala or Spark without Hive, you only need a remote database (such as MySQL), and there is no need to start the Hive metastore process separately;

How to initialize a Hive metadata database?

$ ls $HIVE_HOME/scripts/metastore/upgrade
derby mssql mysql oracle postgres

There are initialization scripts for various versions of various databases in the Hive directory. For example, Impala relies on hive1.2. You only need to install the metadatabase of hive1.2. The corresponding SQL file is:

$HIVE_HOME/scripts/metastore/upgrade/mysql/hive-schema-1.2.0.mysql.sql

which will depend on

$HIVE_HOME/scripts/metastore/upgrade/mysql/hive-txn-schema-0.13.0.mysql.sql

After the initialization is completed, directly configure javax.jdo.option.* in /etc/Impala/conf/Hive-site.XML to point to the MySQL library;

 

The minimal installation of Impala is: HDFS + MySQL (Hive metabase) + Impala

The minimum installation of Spark is: HDFS + MySQL (Hive metabase) + Spark

 

Reference: https://cwiki.apache.org/confluence/display/Hive/AdminManual+Metastore+Administration
