When ssh logs in to the Linux server, there will often be prompts

There were * failed login attempts since the last successful login.

It means there are a large number of illegal login attempts and there are several ways to deal with them.

1 Change the sshd port

However, it is often scanned

2 Disable direct ssh login with root account

Modify /etc/ssh/sshd_config

PermitRootLogin no

Restart sshd after modification

systemctl restart sshd

3 Using fail2ban

Install

yum install fail2ban

Modify configuration

/etc/fail2ban/jail.conf, find [sshd], add enable

[sshd]

# To use more aggressive sshd modes set filter parameter "mode" in jail.local:
# normal (default), ddos, extra or aggressive (combines all).
# See "tests/files/logs/sshd" or "filter.d/sshd.conf" for usage example and details.
#mode   = normal
filter = sshd
port    = ssh
logpath = %(sshd_log)s
backend = %(sshd_backend)s
enabled = true

start up

systemctl start fail2ban

Configure startup

systemctl enable fail2ban

check status

fail2ban-client status sshd

Unrestrictions on an IP

fail2ban-client set sshd unbanip $ip
