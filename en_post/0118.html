Time zone problem when Docker starts Java application

📅 June 13, 2019
📖 1 min read
👁️ 506 views

Start tomcat or Java applications in Docker. The default time to obtain is UTC time. This is because the locale in the container is not set to East 8. The simplest way is to add JAVA_OPTS

If it is Java, add it directly after the Java command.

-Duser.timezone=Asia/Shanghai

If it is tomcat, you can set CATALINA_OPTS first

export CATALINA_OPTS=' - Duser.timezone=Asia/Shanghai '

Start tomcat again
