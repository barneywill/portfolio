Modify the default startup desktop

All desktops are under /usr/share/xsessions. There are two links here to control the default desktop.

ls - l /usr/share/xsessions
total 12
lrwxrwxrwx 1 root root 42 Mar 28 2019 default.desktop - > /etc/alternatives/default-xsession.desktop
-rw-r--r-- 1 root root 5465 Apr 2 2019 xfce.desktop

ln - s /usr/share/xsessions/xfce.desktop /etc/alternatives/default-xsession.desktop

Note: If you find some problems after installing leap on newer computers and hardware, use the tumbleweed version instead. The kernel used by leap 15.2 is 5.3, and the kernel used by tumbleweed has reached 5.9. I self-tested the new computer amd ryzen 7 4800 has various problems when using leap15.2: the display resolution is too low, the screen goes black after sleeping, the screen expansion prompt appears from time to time, and the external typec interface cannot expand the screen. After installing tumbleweed, all problems are solved, and various shortcut keys on the keyboard are available.
