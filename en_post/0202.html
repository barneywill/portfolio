Hive Chinese annotation garbled code

📅 February 26, 2019
📖 1 min read
👁️ 819 views

When viewing the table structure in Hive, the Chinese comments are garbled. There are two situations, one is desc $table, and the other is show create table $table.

1 database character set

examine

mysql> show variables like '%char%';
mysql> show create table COLUMNS_V2;
mysql> show create table TABLE_PARAMS;

Revise

mysql> alter database hive character set latin1;
mysql> alter table COLUMNS_V2 modify column COMMENT varchar(256) character set utf8;
mysql> alter table TABLE_PARAMS modify column PARAM_VALUE varchar(4000) character set utf8;

At this time, desc $table should be able to display Chinese normally, but show create table $table is still garbled. At this time, there are two options:

2.1 Continue to use Hive

Modify org.apache.hadoop.Hive.ql.exec.DDLTask,

outStream.writeBytes(createTab_stmt.toString());
->
outStream.write(createTab_stmt.toString().getBytes(“UTF-8”));

outStream.writeBytes(createTab_stmt.render());
->
outStream.write(createTab_stmt.render().getBytes(“UTF-8”));

And repackage and replace Hive-exec.jar. It is not recommended to change too much.

2.2 Use Spark-SQL or beeline to connect to Spark thrift server
