Docker 4 - utility ctop

📅 February 14, 2019
📖 1 min read
👁️ 1555 views

ctop is similar to top. top monitors processes, while ctop monitors containers (container top).

Install

# wget https://github.com/bcicen/ctop/releases/download/v0.4.1/ctop-0.4.1-linux-amd64 - O ctop
# mv ctop /usr/local/bin/
# chmod +x /usr/local/bin/ctop

use

# ctop

The interface is as follows

You can switch between multiple containers through the cursor. After pressing Enter, the detailed information of a container is displayed.
