The error message is:

class net.sf.cglib.core.DebuggingClassWriter has interface org.objectweb.asm.ClassVisitor as super class

The translation is: ClassVisitor should be an interface, but it is inherited as a class (extends), indicating that there may be a jar package conflict. ClassVisitor is an interface in a jar package and a class in a jar package.

4.2 is dependent on easyexcel-2.0.2.jar, 3.1 is dependent on Hive-JDBC-1.1.0.jar, modify the pom to remove the dependency of 3.1

        <dependency>
            <groupId>org.apache.hive</groupId>
            <artifactId>hive-jdbc</artifactId>
            <version>1.1.0</version>
            <exclusions>
                <exclusion>
                    <groupId>org.slf4j</groupId>
                    <artifactId>slf4j-log4j12</artifactId>
                </exclusion>
                <exclusion>
                    <groupId>asm</groupId>
                    <artifactId>asm</artifactId>
                </exclusion>
            </exclusions>
        </dependency>
