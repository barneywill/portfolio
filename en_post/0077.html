Installing the Oracle Client on Windows

📖 1 min read
👁️ 442 views

1 Download and install plSQL

Official download address: https://www.allroundautomations.com/plSQLdev.html

Registration code:

product code： 4vkjwhfeh3ufnqnmpr9brvcuyujrx3n3le 
serial Number：226959 
password: xs374ca

2 Download oracle client

Official download address: https://www.oracle.com/database/technologies/instant-client/winx64-64-downloads.html

Basic Package（zip）

SQL*Plus Package（zip）

After decompression, merge the directories to get

instantclient_19_5

3 Move the oracle client directory to plSQL

Move instantclient_19_5 to the plSQL installation directory (such as D:\Program Files\PLSQL Developer 13)

Create a new directory and file network/admin/tnsnames.ora under instantclient_19_5

alias =
 (DESCRIPTION =
 (ADDRESS = (PROTOCOL = TCP)(HOST = 192.168.1.1)(PORT = 1521))
  (CONNECT_DATA =
   (SERVER = DEDICATED)
   (SERVICE_NAME = orcl)
  )
 )

Note that the file suffix must be displayed under Windows. A possible pitfall is that the file appears to be tnsnames.ora, but is actually tnsnames.ora.txt, which will cause the configuration to fail.

4 Set environment variables

ORACLE_HOME=D:\Program Files\PLSQL Developer 13\instantclient_19_5
TNS_ADMIN=D:\Program Files\PLSQL Developer 13\instantclient_19_5\network\admin
NLS_LANG=SIMPLIFIED CHINESE_CHINA.AL32UTF8

5 Set up plSQL

MenuConfig-Perferences

Oracle-Connection

set up

Oracle Home=D:\Program Files\PLSQL Developer 13\instantclient_19_5

OCI Library=D:\Program Files\PLSQL Developer 13\instantclient_19_5\oci.dll

6 Start plSQL
