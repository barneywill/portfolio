YARN enables log collection

📅 April 01, 2019
📖 1 min read
👁️ 670 views

YARN enables log collection function, in addition to configuration

yarn.log-aggregation-enable=true

Also check whether the /tmp/logs directory exists and its permissions. Especially after Kerberos is turned on, some directories may not be automatically created successfully and need to be created manually:

$ hdfs dfs - mkdir /tmp
$ hdfs dfs - chmod 777 /tmp

HDFS log directory for each application:

/tmp/logs/$user/logs/$applicationId

If the above log directory exists but still cannot be found

Log aggregation has not completed or is not enabled.

It may be due to user permissions. You can switch to the corresponding user and query again.

# sudo - u $user yarn logs - applicationid=$applicationId
