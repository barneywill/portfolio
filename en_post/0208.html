Docker mounting file modification takes effect

📅 February 23, 2019
📖 1 min read
👁️ 3129 views

Docker often needs to mount files into the container, such as starting Nginx

# docker run - d --name test_nginx - v /tmp/nginx.conf:/etc/nginx/nginx.conf nginx

Then there is the function of modifying the configuration file and then refreshing it. If you directly use vi to edit the host file

# vi /tmp/nginx.conf

Then execute reload in the Docker container

# docker exec - it test_nginx nginx - s reload

You will find that the configuration does not take effect. At this time, directly check the file content in the Docker container and find that it is still old.

# docker exec - it test_nginx cat /etc/nginx/nginx.conf

So it seems that the Docker container can only be restarted. The correct operation method should be

# cp /tmp/nginx.conf /tmp/nginx.conf2
# vi /tmp/nginx.conf2
# cat /tmp/nginx.conf2 > /tmp/nginx.conf
# docker exec - it test_nginx nginx - s reload

This is because the inode of the file will be modified when editing and saving with vi, but cat redirection will not. How to check the inode of the file?

# stat /path/to/file
# ls - i /path/to/file
