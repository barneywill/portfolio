2. Problem recurrence

Configure the broker-list of the Kafka client to a non-existent host, and continuously send messages, execute:

You will find that the file descriptor of the Java process continues to grow, contains a large number of socket connections, and eventually exceeds the limit. You can pass:

ulimit -a|grep 'open files'

To check the limit on the number of file descriptors, if the limit is exceeded, errors will continue to be reported:

three background

1 File Descriptor

Generally, a file descriptor is an index for an entry in a kernel-resident array data structure containing the details of open files. In POSIX this data structure is called a file descriptor table, and each process has its own file descriptor table. The process passes the file descriptor to the kernel through a system call, and the kernel will access the file on behalf of the process. The process itself cannot read or write the file descriptor table directly.

On Linux, the set of file descriptors open in a process can be accessed under the path /proc/PID/fd/, where PID is the process identifier.

 

ulimit -a|grep 'open files'

View process file descriptor limits

cat /proc/sys/fs/file-max

Check the total file descriptor limit of the system

lsof –p $pid

View the specific file descriptors opened by a process

ulimit –n $num

Temporarily modify file descriptor limits
