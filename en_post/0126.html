Remove \r in Windows

📅 May 30, 2019
📖 1 min read
👁️ 2727 views

For Linux, change the line to \n, for Windows, change the line to \r\n. If the Shell script edited in the Windows environment is executed under Linux, an error will be reported:

line 2: $'\r': command not found

Check

# cat - A test.sh
#!/bin/sh^M$
^M$
...

Solution:

vi

1) Replacement

:%s/^M//g

2) Set file format

:set fileformat=unix
