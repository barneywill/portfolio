Creating a Self-Signed HTTPS Certificate

📅 March 28, 2020
📖 1 min read
👁️ 588 views

Replace your.domain in the following commands and configuration with your domain name

1 Generate ca.key

openssl genrsa - des3 - out ca.key 2048

Enter the password of ca.key, more than 4 characters

2 Generate ca.crt

openssl req - new - x509 - days 7305 - key ca.key - out ca.crt

Enter the password for ca.key
Fill in: Common Name (eg, your name or your server's hostname) [] is your.domain

3 Generate your.domain.pem

openssl genrsa - des3 - out your.domain.pem 1024

Enter the password of your.domain.pem, more than 4 characters

4 Generate your.domain.key

openssl rsa - in your.domain.pem - out your.domain.key

Enter the password for your.domain.pem

5 Generate your.domain.csr

openssl req - new - key your.domain.pem - out your.domain.csr

Enter the password for your.domain.pem
Fill in: Common Name (eg, your name or your server's hostname) [] is your.domain

6 Generate your.domain.crt

openssl ca - policy policy_anything - days 1460 - cert ca.crt - keyfile ca.key - in your.domain.csr - out your.domain.crt

Enter the password for ca.key

The last step may report an error:

/etc/pki/CA/index.txt: No such file or directory
unable to open '/etc/pki/CA/index.txt'
139707575097232:error:02001002:system library:fopen:No such file or directory:bss_file.c:402:fopen('/etc/pki/CA/index.txt','r')
139707575097232:error:20074002:BIO routines:FILE_CTRL:system lib:bss_file.c:404:

Solution:

# touch /etc/pki/CA/index.txt

7 nginx configuration certificate

server {
listen 443 ssl;
server_name your.domain;

ssl_certificate /etc/nginx/conf.d/ssl/your.domain.crt;
ssl_certificate_key /etc/nginx/conf.d/ssl/your.domain.key;
