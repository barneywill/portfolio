3 Specify the file system format of the partition

ext2

# mke2fs /dev/sda1

ext3

# mke2fs - j /dev/sda1

ext4

# mke2fs - t ext4 /dev/sda1

btrfs

# mkfs.btrfs - f /dev/sda1

xfs

# mkfs.xfs - f /dev/sda1

3.1 View the file system format of each partition

# parted - l
# file - s /dev/sda1
# df - T

4 Mount the partition to the directory

# mkdir /test
# mount /dev/sda1 /test

4.1 Permanent mounting

# vi /etc/fstab

/dev/sda1 /test ext4 defaults 1 1

5 View directories and partitions

# df - h

 

If you want to mount the disk through uuid, you can view the uuid of each disk partition here

# /dev/disk/by-uuid/
