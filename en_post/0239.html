1 Disk, CPU, memory related

View all device information

# lspci

View overall disk space usage

# df -h

View disk partitions and file systems

# df -T

Check the overall disk inode usage

# df -i

View file details

# ls -l $path

View file inode information

# ls -i $path
# stat $path

View the disk usage of the specified directory, summarize by directory, the depth is 1

# du -h --max-depth=1 $path

# du -sh $path/*

Search for the specified file by name in the specified directory

# find $path -name $file_name

Find all files larger than 100M in the specified directory

$ find $path -size +100M

View disk io

# iostat

Check disk read performance

# hdparm -t /dev/sda

View disk statistics such as power-on time/interface type, etc.

# smartctl -a /dev/sda

View CPU information

# cat /proc/cpuinfo

Check the number of physical CPUs

# cat /proc/cpuinfo| grep "physical id"

Check the number of cores in each physical CPU (i.e. the number of cores)

# cat /proc/cpuinfo| grep "cpu cores"

Check the number of logical CPUs

# cat /proc/cpuinfo| grep "processor" 

View memory information

# cat /proc/meminfo

View remaining memory

# free -m

2 Statistics, load, process related

View overall statistics, including processes, virtual memory, disk, and CPU

# vmstat

View current load

# top

Then enter M to sort by memory usage, enter P to sort by CPU usage, enter H to view threads, and enter c to switch to view detailed startup commands.

Check the resource usage of all threads in a process

# top -H -p $pid

The pid shown here is converted into hexadecimal

# echo 'obase=16;$pid'|bc

Then search for the corresponding thread in jstack;

 

View all current processes

# ps aux

View all threads in the process

# ps -T -p $pid

kill process

# kill $pid

Force kill process

# kill -9 $pid

3 crontab related

View crontab

# crontab -l

Edit crontab

# crontab -e

View crontab log

# tail -f /var/log/cron

4 Network port related

View network information

# ifconfig

View ip routing information

# ip route get 1

Check the port bound to a certain process or which process a certain port is bound to.

# netstat -tnlp|grep $pid
# netstat -tnlp|grep $port

Check port occupancy

# lsof -i:$port

Check the binding and connection status of a certain port

# netstat -nat|grep $port

Capture packets for ports

# tcpdump -i eth1 tcp port $port -Xxv

Modify static ip

# vi /etc/sysconfig/network-scripts/ifcfg-ens33

TYPE=Ethernet

PROXY_METHOD=none

BROWSER_ONLY=no

BOOTPROTO=static

IPADDR=192.168.1.252

NETMAST=255.255.255.0

GATEWAY=192.168.1.1

DEFROUTE=yes

IPV4_FAILURE_FATAL=no

IPV6INIT=yes

IPV6_AUTOCONF=yes

IPV6_DEFROUTE=yes

IPV6_FAILURE_FATAL=no

IPV6_ADDR_GEN_MODE=stable-privacy

NAME=ens33

UUID=989f4fa4-d0d5-4592-8891-99a50a1bb4a7

DEVICE=ens33

ONBOOT=yes

# service network restart

5 Compression and decompression related

Make the directory into a tarball

$ tar cvf $tar_name.tar $dir_name

$ tar cvf $tar_name.tar $dir_name --exclude $exclude_file --exclude $exclude_dir

Exclude specified directories

$ tar cvf $tar_name.tar $dir_name --exclude $dir_name/$exclude_name

Unzip the tarball

$ tar xvf $tar_name.tar

Unzip the tarball to the specified directory -C $target_dir

Compress the tar file and get *.tar.gz

$ gzip $tar_name.tar

Unzip tar.gz

$ tar xvf $tar_name.tar.gz


Make the specified directory into a zip package

$ zip -r $zip_name.zip $dir_name

Unzip the zip package

$ unzip $zip_name.zip

Unzip the zip package to the specified directory -d $target_dir

6 Software package related

View installed packages

# yum list installed

Find packages

# yum search $name

Install packages

# yum install $name

Download the software package and all dependencies to the specified directory

# yum install --downloadonly --downloaddir=$dir $name

Uninstall a package

# yum remove $name

Check which package a command is in

# yum whatprovides $cmd

rpm installation

# rpm -ivh $name.rpm

yum install rpm package

# yum localinstall $name.rpm

The difference between the above two is that yum localinstall will automatically install the discovered dependencies.

rpm query installed

# rpm -qa | grep $name

rpm uninstall

# rpm -e --nodeps $name

7 Shell related

View current Shell

# echo $SHELL

View all shells

# cat /etc/shells

Modify default Shell

# chsh -s /bin/zsh

8 others

Check which users are currently logged in

# w

Switch to other users to execute commands

# su - $user -c 'whoami'

Find where the command is

# whereis $cmd

View command path

# which $cmd

View previously executed commands

# history

View system limits

# ulimit -a

Execute commands in the background

# nohup $cmd $arg 1>output.log 2>&1 &

Set time zone

# timedatectl set-timezone Asia/Shanghai

copy

# cp -R /source /target

Copy shows progress and speed

# rsync -rv --progress /source /target
