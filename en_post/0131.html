If your compiler is GCC-4.9.0 or a version below VS2013, please upgrade before using it. The C++ compiler I used before was GCC 4.8.3, which had the regex header file, but GCC was very unkind and didn't implement it. The syntax was fully supported, but the library hadn't caught up yet, so there was no problem when compiling, but an exception would be thrown directly when running.
