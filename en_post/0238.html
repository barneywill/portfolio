Commonly used JVM tools for Java basics

📅 January 30, 2019
📖 1 min read
👁️ 327 views

View all current Java processes

# jps

Check the heap memory usage of a process

# jmap - heap $pid

Check the distribution of objects in the heap memory of a process

# jmap - histo $pid

Export the heap memory of a process to a file

# jmap - dump:format=b,file=test.dump $pid

Analyze heap memory export file

# jhat test.dump

You can also use eclipse Memory Analyzer: http://www.eclipse.org/mat/

Check the gc status of a process

# jstat - gcutil $pid

View the thread stack of a process

# jstack $pid

View the signature of a class in a jar package

# javap - cp $jar_path $class_name

View all files (classes, configurations, etc.) in a jar, equivalent to list

# vim $jar_name

or

# unzip - l $jar_name
