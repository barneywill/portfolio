1 download iso

opensuse

download:

http://download.opensuse.org/distribution/openSUSE-stable/iso/openSUSE-Leap-15.0-DVD-x86_64.iso

Taking the c drive as an example, copy the iso to the root directory of the c drive, and at the same time place the two files in the iso into the root directory of the c drive.

boot/x86_64/loader/linux

boot/x86_64/loader/initrd

ubuntu

https://www.ubuntu.com/download/desktop

Taking the c drive as an example, copy the iso to the root directory of the c drive, and at the same time place the two files in the iso into the root directory of the c drive.

casper/initrd.lz

casper/vmlinuz.efi

 

2 Download easybcd2.3 

operate

Add New Entry - > NeoGrub - > Install - > Configure

Notepad will pop up, then edit

opensuse

title Install openSUSE
root (hd0,0)
kernel (hd0,0)/linux boot=casper iso-scan/filename=/openSUSE.iso ro quiet splash nouveau.modeset=0
initrd (hd0,0)/initrd

ubuntu

title Install Ubuntu
root (hd0,0)
kernel (hd0,0)/vmlinuz.efi boot=casper iso-scan/filename=/ubuntu.iso
initrd (hd0,0)/initrd.lz
title reboot
reboot
title halt
halt

The default c drive is (hd0,0). If the file cannot be found, you can change it to (hd0,1), or you can directly check the disk number of the c drive from the disk management; in addition, the iso file name should be changed to the actual file name;

Then there will be an additional startup entry, NeoGrub Bootloader. After restarting Windows, select the new startup entry and follow Linux;

 

If it is an NVIDIA graphics card, the green progress bar may be stuck when installing opensuse. In this case, you need to add

nouveau.modeset=0

That’s it, see the configuration above for details;

 

After installing Linux, go back to Windows, delete the newly added startup entry NeoGrub Bootloader, and then add a new Linux startup entry. Drive select the disk you just installed.
