core enumeration

public enum ServerState {
    LOOKING, FOLLOWING, LEADING, OBSERVING;
}
ZooKeeper server status: LOOKING has just been started, the follower is FOLLOWING, the leader is LEADING, and the observer is OBSERVING;
public enum LearnerType {
    PARTICIPANT, OBSERVER;
}

To put it simply, the core class started by ZooKeeper is QuorumPeerMain. After startup, the configuration will be loaded and QuorumPeer will be started at the same time. QuorumPeer will load data from the local data directory and then start the election. The core class of the election is FastLeaderElection. After the election is completed, the status will be set. Depending on the status, different classes will be started, such as Leader, Fo The lllower, Observer, and leader will set a new epoch and wait for the follower to register with itself. After the registration is completed, the follower will synchronize the latest data with the leader, and the leader will ping all followers regularly. Once less than half of the followers survive, the leader will shut down and trigger a re-election of the cluster.
