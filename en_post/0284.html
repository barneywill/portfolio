Supervised Learning Supervised Learning

The existing sample data (TrainingSet) includes input (Input) and output (Output), use the sample data to train (Train) the model function (Model), and finally bring the unknown input (UnknownInput) into the model function to predict the output (Output)

The supervised learning process is as follows:

TrainingSet(Input & Output) - > Train - > Model - > Predict(UnknownInput - > Output)

That is, training set (containing input and output) -> training -> model -> prediction (unknown input -> output)

 

1 Classification

Classification belongs to supervised learning. The classification problem is solved when a sample is given and the predictor variables are discrete. For example, in content category prediction, given a piece of content, the category needs to be predicted: sports, society, finance, etc.;

2 Regression

Regression belongs to supervised learning. The regression problem is solved when a sample is given and the predictor variable is continuous. For example, in stock price prediction, given one day's price and other information, it is necessary to predict the next day's price;

Three Clustering

Clustering does not belong to supervised learning. The clustering problem is to solve, given a set of samples, predict which samples are closer to each other and which samples are further apart. For example, in user grouping, users are divided into multiple categories based on the definition of categories, such as interest, purchasing power, etc.;
