📅 February 20, 2019
📖 1 min read
👁️ 938 views

1 在一个能访问远程repo的服务器上执行，下载ansible及相关依赖的rpm包

# mkdir ansible
# yum install --downloadonly --downloaddir=ansible ansible

 

2 将ansible目录拷贝到离线服务器上，通过yum localinstall安装
