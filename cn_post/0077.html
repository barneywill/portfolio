2 下载oracle客户端

官方下载地址：https://www.oracle.com/database/technologies/instant-client/winx64-64-downloads.html

SQL*Plus Package（zip）

解压后将目录合并得到

instantclient_19_5

3 将oracle client目录移动到plsql下

移动instantclient_19_5到plsql安装目录（比如D:\Program Files\PLSQL Developer 13）下

在instantclient_19_5下新建目录和文件network/admin/tnsnames.ora

alias =
 (DESCRIPTION =
 (ADDRESS = (PROTOCOL = TCP)(HOST = 192.168.1.1)(PORT = 1521))
  (CONNECT_DATA =
   (SERVER = DEDICATED)
   (SERVICE_NAME = orcl)
  )
 )

注意windows下一定要显示文件后缀，有可能的坑是文件看起来是tnsnames.ora，实际是tnsnames.ora.txt，这会导致配置失败

4 设置环境变量

ORACLE_HOME=D:\Program Files\PLSQL Developer 13\instantclient_19_5
TNS_ADMIN=D:\Program Files\PLSQL Developer 13\instantclient_19_5\network\admin
NLS_LANG=SIMPLIFIED CHINESE_CHINA.AL32UTF8

5 设置plsql

菜单Config-Perferences

Oracle-Connection

设置

Oracle Home=D:\Program Files\PLSQL Developer 13\instantclient_19_5

OCI Library=D:\Program Files\PLSQL Developer 13\instantclient_19_5\oci.dll

6 启动plsql
