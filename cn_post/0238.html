Java基础之常用JVM工具

📅 January 30, 2019
📖 1 min read
👁️ 327 views

查看当前所有java进程

# jps

查看某个进程的堆内存占用情况

# jmap - heap $pid

查看某个进程的堆内存中对象分布情况

# jmap - histo $pid

将某个进程的堆内存导出文件

# jmap - dump:format=b,file=test.dump $pid

分析堆内存导出文件

# jhat test.dump

也可以用eclipse Memory Analyzer：http://www.eclipse.org/mat/

查看某个进程的gc情况

# jstat - gcutil $pid

查看某个进程的线程堆栈

# jstack $pid

查看某个jar包中某个类的签名

# javap - cp $jar_path $class_name

查看某个jar中所有的文件（类、配置等），相当于list

# vim $jar_name

or

# unzip - l $jar_name
