上传下载

📅 January 14, 2019
📖 1 min read
👁️ 219 views

1 rz sz

安装

yum install - y lrzsz

上传

rz ，对话框操作

下载

sz $filename

注意：rz不能上传大于4g的文件，此时可以改为scp或sftp上传，其中sftp url为：sftp://user:passwd@host:22

2 scp

安装

yum install scp

上传

scp /local_dir/filename user@server_ip:/remote/path 

下载

scp user@server_ip:/remote/path/filename /local_dir

 

3 windows pscp

pscp /local_dir/filename user@server_ip:/remote/path
