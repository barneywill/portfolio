An extensible, customizable, free/libre text editor — and more.

一 安装

# yum install emacs

# apt-get install emacs

# zypper in emacs 

windows和mac也可下载安装

二 配置

配置文件： ~/.emacs

三 快捷键

1 文件相关操作

Ctrl+x Ctrl+f （打开文件）

Ctrl+x Ctrl+s （保存）

Ctrl+x Ctrl+w （写文件）

Ctrl+x Ctrl+v （关闭文件并打开）

Ctrl+x k （关闭文件）

Ctrl+x b （切换下个文件）

Ctrl+x Ctrl+b （展示所有文件列表）

Ctrl+x Ctrl+c （退出emacs）

2 窗口相关操作

Ctrl+x 2 （水平拆分窗口）

Ctrl+x 3 （垂直拆分窗口）

Ctrl+x 0 （关闭当前窗口）

Ctrl+x 1 （关闭其他窗口）

Ctrl+x o （切换窗口）

3 移动光标

Ctrl+f （下一个字符）

Ctrl+b （上一个字符）

Ctrl+n （下一行）

Ctrl+p （上一行）

Ctrl+a （行首）

Ctrl+e （行尾）

Cmd+f （下一个单词）

Cmd+b （上一个单词）

Cmd+< （文件头）

Cmd+> （文件尾）

Ctrl+v （下一页）

Cmd+v （上一页）

4 搜索

Ctrl+s （向下搜索）

Ctrl+r （向上搜索）

5 删除

Ctrl+h

Ctrl+d

Ctrl+k
