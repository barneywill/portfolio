git大面积修改问题

📅 July 20, 2020
📖 1 min read
👁️ 282 views

最近把git工程目录移动到其他目录之后,发现git工程内出现大面积修改,

通过git status查看

	modified:   .gitignore
	modified:   .README.md
...

通过git diff查看

diff --git a/.gitignore b/.gitignore
old mode 100644
new mode 100755
diff --git a/README.md b/README.md
old mode 100644
new mode 100755
...

发现这些文件没有文件内容的变化,只有file mode的变化,file mode从644到755

这时有两种解决方法:

  • 通过chmod修改file mode
  • git config --add core.filemode false
